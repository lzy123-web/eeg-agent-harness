# EEG 科学意图验证研究判断

日期：2026-10-24（Asia/Shanghai）

## 结论

当前决策：**工程 Keep，独立论文贡献 No-Go / 证据不足**。

EEG Intent Compiler v1 解决了一个真实问题：同一正确 IntentSpec 在固定短语 anchor 下会被错误拒绝。类型化 Claim–Evidence、注册要求投影、科学先决条件闭包和高风险授权作用域比单纯 Prompt 或 JSON Schema 多了一层可审计、可执行的语义边界，并已接入真实 CIEDG Agent，而不是离线分类器。

但是一次性 holdout 暴露了 1 个重复出现的 dangerous accept：转换前质量与转换后功率的混合阶段请求被错误合并执行。与此同时，严格原始字段正确率很低，模型版本替换没有消除任务分解和授权理解错误。候选还没有证据支持“可靠 EEG 科学意图验证”或独立于 CIEDG 的第二研究创新点。

## 必要工程修复

- 记录 API response model、请求预算和 token 用量；
- 将模型字段错误与 validator 错误分层评分；
- 统一 JSON 可复现结果与合成数据隐私边界；
- 请求侧禁止项规范化、schema 检查和结构化错误码；
- 对混合转换阶段 fail closed。

这些工作提高可靠性，但本身不应包装为论文创新。

## 可能具有研究价值的部分

- 从注册 EEG 工具契约投影出必需槽、先决目标和合法状态阶段，而不是让 LLM 自由生成完整工作流；
- 将普通科学 claim 的表达弹性与数据变换授权的严格作用域分离；
- 使用同一原始模型载荷做 v0/v1 因果对照，从而识别模型误解、语义校验误拒和运行时失败。

这些机制有潜在研究价值，但当前仅有少量合成、单次模型输出和单人标注，且存在安全反例，不能宣称已经形成独立贡献。

## 模型替换与 Harness 改进各解决多少

- 从 Flash 换成 V4 Pro：严格字段全对从 2/9 到 3/9，但 v1 端到端正确从 5/9 降到 3/9，dangerous accept 均为 1。小样本下不能认为换模型解决了问题。
- 从 v0 换成 v1：Flash 决策从 2/9 到 5/9，Pro 从 2/9 到 3/9；但 v1 新增/暴露 H14 dangerous accept。它减少了部分误拒，却尚未达到安全替代条件。
- 结论：模型与 Harness 是两个独立误差源；任何一方单独升级都不够。

## 后续边界

1. 不在本次 holdout 上补英文词形或改 gold。H14 固定为回归反例。
2. 若继续研究，应新预注册协议，采用独立双人标注，并把“转换前后阶段/分支”提升为类型化时序关系，而不是增加短语词表。
3. 新方法必须与冻结 v0、原生 Agent、同规则 validator/NLI 基线比较，并报告 dangerous accept 优先于总准确率。
4. 在安全反例关闭前，不将 v1 设为默认路径，不修改冻结 CIEDG，也不把本结果写成第二创新点。
