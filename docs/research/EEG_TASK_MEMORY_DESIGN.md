# 多轮 EEG 任务上下文管理：方法边界与最小设计

## Issue #42 当前候选收敛（下文旧版本说明保留为研究时间线）

本轮把已存在的任务 episode、不可变版本、真实 EEG 工具结果与按需证据读取组合成一个可运行入口 `python -m eeg_harness.research.task_memory_issue42 --offline`；带独立预算的真实运行另需显式阶段和本地配置。流程为：当轮用户请求 → 公共动作决定真实分析/修订/澄清 → Registry/Executor 返回任务状态及数值 → 完成条目与原始证据同存 → F/S/HC 仅选择不同工作视图 → 历史追问可直接用可见精确值或以用户原文的局部科学范围作有限读回 → 带来源的回答。公共比较 `scope_quote` 不接受编造或遗漏多个互斥对象的限定词；不是额外 EEG Planner。

方法身份是**HiAgent 启发的任务块/摘要/恢复在多轮 EEG 真实证据上的领域适配**，不是原 HiAgent 算法复现。EEG 特有设计在于记录、连续窗/事件条件、版本、来源及单位一同绑定和校验；执行器、强 S 的通用摘要及 F 全历史均为共享能力。HC 的小结果保留/大结果索引是可选成本策略。Issue #42 完整连续任务三臂同效，事件混合任务 HC 虽末轮正确但中途漏证且更贵；故推荐公共科学历史 + 强 S 为默认，HC opt-in，HE 继续暂置。详细冻结条件、原始与追加评分、失败归因及预算见 `EEG_TASK_MEMORY_ISSUE42_PROTOCOL.md` / `EEG_TASK_MEMORY_ISSUE42_RESULTS.md`。

## 原始研究与本项目推断

- [HiAgent（ACL 2025）](https://aclanthology.org/2025.acl-long.1575/) 将子目标作为工作记忆块，保留当前子目标详细行动—观察，完成的子目标摘要化且可追索轨迹。它研究**单次长任务内** working memory；跨用户轮次、EEG 对象和分析版本是我们的适配，不声称复现其完整方法或论文成绩。官方[代码](https://github.com/HiAgent2024/HiAgent)仅用于核对公开设计；本项目不拷贝其实现。
- [LongMemEval](https://arxiv.org/html/2410.10813) 是聊天长期记忆 benchmark，提出索引→检索→读取的统一视角，评价信息抽取、跨会话、时间推理、知识更新和拒答。本项目只借鉴问题拆分与评价维度，不把其 500 问题直接当 EEG benchmark。
- [EEGAgent](https://arxiv.org/html/2511.09947v2) 已论述工具规划中的上下文、知识检索、记忆和用户互动；[BrainAgent 预印本](https://arxiv.org/html/2606.25400v1) 描述有全局对话历史的 supervisor 与子代理隔离。不能说“EEG Agent 首次引入记忆”，也不从论文未测多版本 EEG 追问推断已有系统必失败。

**可证伪假设**：在相同可见对话与真实工具证据、正常长度和预算下，按分析任务保存不可变历史，把记录/科学作用域/参数版本与结果绑定并检索，可能减少多轮 EEG 中错用记录、窗口、事件条件和旧结果的错误，或以接近的准确性减少上下文成本。若强通用结构化记忆 G 已同样准确且成本相近，则复杂领域适配不值得继续。

## 共同接口与候选差异

所有臂共用 `MultiTurnEEGSession`：用户消息；记录别名对应隔离的 `ExecutionContext`；真实 `ToolResult` 与不可变 task entry；通用 `read_task(task_id)` 只读证据；新分析统一走原 `run_instances`→Registry/Executor，修订创建新 entry 并保留旧 entry。切换记录只改变可见当前别名，不能跨记录拿 artifact。当前请求的任务解析及回答格式对 F/S/G/E 相同；不能让候选独享 TaskSpec 或 gold ID。

F：完整历史与所有 task card；S：最近 3 个 task card + 早期条目的通用滚动摘要（保留标识、记录、类型、窗/事件、数值结果入口，不故意删除关键事实）；G：HiAgent/LongMemEval-inspired 的任务块与通用字段/词面检索，允许 record/time/field 和历史只读读取；E：在 G 的信息上增加 EEG 科学对象（连续窗/事件 Epoch）、来源/配置与不可变修订关系的索引与排序。G/E 都能读取相同完整条目，区别只是挑选工作上下文；F 不压缩且成本单独报告。消融 E−scope 去掉 EEG 作用域排序，其余相同。G 若已能解决，则如实持平。

历史写入仅取当前用户文本、实际已解析目标、真实执行 bundle/ToolResult；未来请求与离线 gold 不进记忆。检索条件只取当前可见请求、活跃记录与历史字段；遇到多解不猜。项目仅实现轻量本地索引与按需读取，不新建向量数据库、不改 EEG 数值工具、Executor、Planner 或旧 v3 方法。HiAgent-inspired 指任务块/已完成摘要与外部详细证据，LongMemEval-inspired 指分离索引、检索与读取；科学对象/版本关联是 EEG 适配，不是新通用记忆算法。

## 实际实现审计（实验后追加，不改变冻结假设）

`src/eeg_harness/research/task_memory.py` 的 `TaskEntry` 按实际完成的分析任务写入 `task_id`、记录别名、能力、参数、用户话语、`revision_of`、真实结果和 v3 evidence/tool trace。修订只追加新任务；历史读取在公共 `MultiTurnEEGSession.read_task` 中读取对应不可变条目。记录 A/B 是可区分的合成数据，各分析新建原有 `ExecutionContext` 并调用 `run_instances`，事件产物只在该次执行链内使用，不能由别的记录复用。当前轻量实现不是持久化数据库，也不支持跨进程恢复。

F/S/G/E 共用该写入和读取路径；`select_context` 只改变当前提供给模型的工作任务卡。G 用普通词面、记录、通道字段排序，E 在同一索引上增加连续/事件能力、事件标签和修订前后关系排序。E−scope 去掉后一组排序。E 的实现**没有**新 EEG 数值算法或独占正确任务 ID；科学来源、方法配置等保存在真实 evidence 中，但尚未全部进入检索特征。有限中英文字面提示仍是脆弱近似，不能宣称开放语言泛化。

`live_turn` 统一使用一次结构化 `submit_memory_action`，执行后可选第二次模型调用生成有证据边界的自然语言答复。共同能力目录从现有 `capability_catalog` 生成，所有臂共享，修复只改公共接口而非 E 策略。该两阶段交付是在真实工具结果上作答；模型只见合成记录元数据、必要任务卡/结果，不见 EEG 数组。完整原始响应保留在 Git 忽略的本地实验目录。

这是一项**HiAgent/LongMemEval 启发的最小领域适配**，不是对其完整实现或论文成绩的复现。当前 6 会话的任务历史过短，G/E 同为全部命中，S 摘要未真正触发；因此工程机制可运行，但 EEG 作用域排序的独立研究收益尚无充分证据。参见 `EEG_TASK_MEMORY_RESULTS.md` 和 `EEG_TASK_MEMORY_DECISION.md`。

## PR #37 阶段审查后的 v2 设计冻结（实施前）

不改变旧 v1 文件和原结果；新选择器、协议与离线评价以 v2 命名。先依据 [HiAgent 原文](https://aclanthology.org/2025.acl-long.1575/) 与 [LongMemEval 原文](https://arxiv.org/html/2410.10813) 明确借鉴边界：

| 层 | 成熟方法启发 | 本项目 v2 的实际机制 | 不声称 |
|---|---|---|---|
| 任务级组织 | HiAgent 用子目标将工作记忆分块，完成的块可摘要而保留详细轨迹 | 把每次实际执行的 EEG 分析作为不可变任务块；任务卡、完整证据与原始消息分开存储 | 未复现 HiAgent 的 LLM 自主子目标生成、主动摘要决策或其论文性能 |
| 摘要 | HiAgent 完成子目标后以摘要替代冗余行动—观察 | S 对超过最近 3 条的任务生成确定性通用摘要索引，保留记录、能力、参数、版本、结果字段和公共读取 ID；G/E 可检索同一任务块 | 不是 HiAgent 的模型生成摘要，也不宣称压缩质量已验证 |
| 检索/读取 | LongMemEval 将索引、检索、读取拆开；时间查询扩展是其研究内容之一 | 所有臂共享完整条目和 `read_task`；G 具备通用词面、记录、时间窗、序列与版本检索；E 仅加实际 EEG 通道/事件标签/连续或事件作用域一致性 | 不复现 LongMemEval benchmark、训练检索器或其指标 |
| 证据 | 属于现有 Harness 的 ToolResult/evidence_bundle，并非上述论文提出的 EEG 算法 | 历史数值、单位、来源与修订关系只从实际工具输出写入；读取返回原始证据并接受独立数值 oracle | 不把证据序列化或普通安全校验包装为新记忆理论 |

选择时先从当轮可见请求、当前记录和任务历史构建查询，事件标签只从实际 `EventSet`/历史任务参数取得，通道只从记录元数据取得；不写死 `stimulus/control` 或扩测试句式词表。G 与 E 共用通用记录、时间/版本选择，E 只在科学对象/作用域匹配上增加结构化排序。F 保留完整历史；S 最近任务为完整卡，早期块只显示常规摘要索引而可用共同 `read_task` 读取。`top_k=3` 与最近 3 条沿用旧设置而不人为压低，新增 6/10 任务历史使压缩与选择真正发生。

评价先隔离上下文，再看动作：相同真实历史上的检索/读取回放只评目标是否可见、排序、科学范围和结果忠实；实际 `analyze`/`switch` 误选另记为共同动作错误，不用其级联澄清推断记忆坏。旧 `score_live_turn` 只对 task ID 的判断不能作为 v2 语义结论；v2 评分以真实记录、能力、通道或事件范围、版本祖先、来源与结果字段为准。详细冻结脚本及未授权付费预算估算见 `EEG_TASK_MEMORY_PROTOCOL_V2.md`。

### v2 实际实现与一次公共契约修订

`task_memory_v2.py` 复用原 `MultiTurnEEGSession` 和 `live_turn`，未建第二套 Executor。`protocol_records` 从协议/真实事件集合获得标签；任务摘要只压缩可见卡，原始结果仍可由同一 `read_task` 恢复。G 的检索含通用词面、显式记录、参数值、时间窗和通用修订前/后，E 再用 EEG 连续/事件对象及实际通道/事件条件加科学一致性排序；所有臂可见同一任务条目和证据。完成任务的结果不是摘要模型编造的文字。研究代码是轻量确定性索引，**不是** HiAgent 完整算法、向量检索平台或新的 EEG 知识图谱。

首次离线回放后检查任务卡发现来源阶段、单位、分析配置只在底层证据而不在所有臂的工作卡/摘要中。故一次性在公共 `_summary` / `_full_card` 补齐这些**既有真实 evidence** 字段；G/E 均获同一信息，科学 oracle 和目标未改，首次产物保留。该修订解决通用接口可见性，不视为候选增益。v2 的工作上下文与所有数值链只在合成数据上验证，未来 LLM 对摘要的理解仍未实测。

## Issue #38：任务 episode 的 HiAgent→EEG 适配落实

本阶段不重选题。对照 [HiAgent 原文](https://aclanthology.org/2025.acl-long.1575/)：其原问题是**一次长任务内部**的行动—观察工作记忆，先由模型提出子目标，再主动决定何时以摘要替代已完成子目标的轨迹。这里把实际已选择并落地的 EEG 分析目标作为 episode 边界，跨用户轮次保存；这不是原论文实验设置，亦未实现其 LLM 子目标生成与主动摘要决策。[LongMemEval](https://arxiv.org/html/2410.10813) 仅为索引、检索、读取及历史更新的评价分层参考。

| 原始机制/问题 | v1/v2 已有 | 本阶段具体落实 | 边界与可测试行为 |
|---|---|---|---|
| 子目标边界与当前任务 | 每次成功分析记 `TaskEntry`，但执行前后没有可见生命周期 | `EpisodeMemorySession.analyze` 从公共 `analyze/revise` 动作和实际 `run_instances` 状态建立 active episode；失败保留请求、参数、真实工具观察为 blocked；同记录/能力/修订父项的下一次完整参数请求可 resume | 不从离线 gold 取目标；一次同步工具链内没有 LLM 逐工具互动；测试 started→blocked→resumed→archived，换任务或切记录不默默拼接旧状态 |
| 当前详细行动—观察、已完成压缩 | v2 S 是最近 3 条详细卡加早期摘要；G/E 是检索出详细卡 | H/HE 在任务实际完成时写入紧凑摘要缓存，完整结果仍保存在不可变真实条目；工作上下文为 active 详情、被选中任务的完整卡、其他完成任务的摘要索引。摘要仅含实际记录/能力/参数/版本、来源/阶段/单位/配置、结果字段路径及证据读取 ID；数值仍在原始结果 | 压缩不是 LLM 生成新结论；不存在“摘要即临床解释”。短历史无需在工作上下文归档，6/10 任务触发 3/7 条归档显示；旧 v1/v2 继续可跑 |
| 需要时恢复原始轨迹 | 共同 `read_task` 已返回完整数值，但未把真实行动—观察作为当前焦点 | `EpisodeMemorySession.read_task` 对成功读回追加真实 `tool_trace`、来源阶段、分析配置，并把该任务作为下一轮 focused evidence；新分析或切记录清除焦点，避免隐式携带 | 所有策略使用相同只读证据操作；历史读回不重新计算 EEG；Fake 连续轮次检查焦点与执行次数 |
| EEG 科学对象/版本适配 | G 已有通用记录/时间/版本检索，E 仅加 EEG scope 排序 | HE 仅对实际同记录、同来源阶段、同分析能力与通道/事件条件的**多版本**对象建立分组；各版本的时间窗/修订父项仍分开。公共读取入口对显式记录、连续/事件、通道/事件标签、窗口和版本冲突保守拒绝 | 分组不合并不同记录或条件；科学校验给 F/S/H/HE 同等使用，不是 HE 独占金标或工具。查询解析仍有限，未知语义须澄清，不能称科学意图完备性证明 |

对照映射：F 为不截断完整历史强参考；S 为通用摘要；G 为 v2 强通用结构化检索；E 为 v2 EEG 附加排序，均保留历史。H 为**任务 episode 的直接迁移**：active 详情、完成任务紧凑索引、通用 G 检索和证据恢复；HE 在 H 上加实际 EEG 科学对象分组，并沿用 v2 E 的作用域检索。H/HE 看同一历史、工具结果和读取接口，HE 不独占任务 ID/标签/时间/版本。F/S/H/HE 在 Issue #38 中配对回放；G/E 是另存的强检索对照，不能为了让 HE 显得有效而撤掉 G 的时间/版本能力。

**共同调用链**：自然语言 → 原 `live_turn` 结构化动作 → `EpisodeMemorySession` 的任务 episode → 原 `run_instances` → 原 Registry/Executor → 实际 ToolResult/trace → 不可变完成条目或 blocked active → `select_context_v3` 压缩/选择 → 公共 `read_task` 恢复证据 → 模型或 Fake 的下一轮。只新增 opt-in 研究层与 CLI 模式，不修改 EEG 数值算法、旧 CIEDG 或 Executor。当前 episode 生命周期以实际工具状态为准；若模型首轮把 `analyze` 误选成 `switch`，任务根本不会产生，记忆层不能补救。

**实现后修订**：首轮回放显示 HE 为每个单例也重复写一份科学绑定，增加约千字符而没有命中收益。这是组织冗余而非额外科学信息，故仅保留确有多个版本的对象分组；首次本地回放保留。其后增加所有臂共享的显式科学范围读取校验：错记录、事件条件、通道、窗口或明确旧/新版本不恢复为可引用数值，返回 `SCIENTIFIC_SCOPE_MISMATCH`。这项安全约束使用真实任务及记录元信息，不使用 gold，但仍是规则型适配，不声称开放语言覆盖或新通用记忆算法。

## Issue #39：真实评价后的方法版本与归属

当前 opt-in v3 的核心不是额外 EEG 数值算法，而是以下闭环；所有臂共用 `EpisodeMemorySession`、合成记录、既有 `run_instances`→Registry/Executor、不可变真实结果和 `read_task`：

```text
用户轮次 → 公共结构化动作(analyze/revise/switch/history/clarify)
  → 真实工具状态决定 active / blocked / archived
  → 完成时写入不可变 TaskEntry + 任务摘要（不让 LLM 编造数值）
  → 下一轮 H/HE: 通用任务检索 → 工作集摘要 + 其余完成任务索引
  → history(task_id) 经公共科学范围检查恢复原 ToolResult/trace
  → 最终回答只依据此次执行或读取结果
```

`--memory-variant original|optimized` 可在 `task_memory_eval --mode replay-v3` 跑同一合成历史的旧 v3 与 Issue #39 压缩版；默认 optimized。旧版 H/HE 将选中任务的完整 result 放入工作集，`result_fields` 为前 24 个叶路径；新版只放真实任务摘要、顶层结果字段和读取 ID，完整数值需通过公共读取恢复。`original` 是研究版本，不作为新的独立对照臂；F/S 始终保持各自合理信息权限。版本开关不创建第二套 Executor、不影响冻结 CIEDG，也不覆盖旧实验日志。

| 层次 | 来自何处 | 本轮可支持的主张 |
|---|---|---|
| 子任务/工作记忆块、已完成摘要与按需恢复 | HiAgent 启发；本项目并未复现其 LLM 子目标生成、主动摘要决策或原基准 | H/HE 的任务摘要选择与真实读取可运行；同历史离线工作上下文缩短，真实闭环净收益未证 |
| 通用任务 ID、时间/版本检索、旧结果读取和公共动作/范围校验 | Harness 公共工程，F/S/H/HE 同权 | 可安全保留旧任务、跨记录绑定修订、拒绝不一致读取；不能记作 HE 独立贡献 |
| EEG 记录来源、连续/事件范围、通道、事件条件、参数版本的对象组 | HE 领域适配；输入来自实际数据/工具状态，不来自 gold | 结构存在且可追溯，但本次真实对照没有发现相对 H 的稳定正确性或成本增益，不能宣称论文方法优势 |
