# Issue #40：同历史任务记忆效用归因与方法收敛

日期：2026-10-25。分支 `research/point1-eeg-task-memory`、Draft PR #37。调用前冻结协议见 `EEG_TASK_MEMORY_ISSUE40_PROTOCOL.md`；Issue #39 的失败、预算截断、报告和提交均原样保留。本轮不改 CIEDG、Planner、EEG 数值工具或科学真值。

## 范围与证据

- 三份合成 EEG 脚本历史含 3、6、10 个真实 Registry/Executor 完成的分析任务，各有两条历史追问。每个问题只生成一次历史快照，F/S/H/HE 从深拷贝读取完全相同的 task ID、artifact/evidence token 和结果；问题间独立重置。开发 3 单元、确认 3 单元均出自既有已见脚本；确认仅表示本轮未用来调方法，**不是外部未见集**。
- 统一结构化 `answer(task_id, answer)` / `read(task_id)` / `clarify(question)`；四臂共享真实 `read_task` 来源、窗口、事件、通道与版本守卫。F 有直接回答权。H 工作卡不含精确数值，通常需按需读取。gold、目标 ID 和独立原数组 oracle 均只在响应后评分，不送模型。
- 24 个回答以独立 NumPy/SciPy oracle 重算目标值、核对记录/能力/参数/修订/来源/单位，再逐条审阅自然语言的数值与科学条件。自动数值筛选不能代替审阅。原始响应、实际用量和账本留在 Git 忽略的 `artifacts/point1_task_memory/issue40/`；未提交或外发真实 EEG、受试者明细、密钥或权重。
- 请求 `deepseek-chat`，57/57 次有效响应均报告 `deepseek-flash`。Issue #40 独立追加账本累计 **57 completion / 103,906 API tokens**，低于 96 / 240,000 硬上限；0 个未结算尝试。含首次闭环及修正后复核，不与 Issue #39 配额相加。

## 完整四臂同历史配对

“有效”同时要求目标证据 ID、记录、科学范围、参数/版本、来源、单位、独立重算标量与最终回答一致；同值但错目标不计正确。

| 方案 | 开发 3 问 | 确认 3 问 | 合计 | completion | API tokens | 六问累计延迟 |
|---|---:|---:|---:|---:|---:|---:|
| F 完整历史 | 3/3 | 3/3 | 6/6 | 6 | 19,031 | 9.48 s |
| S 普通摘要 | 3/3 | 3/3 | 6/6 | 9 | 19,364 | 10.91 s |
| H 任务 episode＋按需读取 | 3/3 | 3/3 | 6/6 | 12 | 18,141 | 14.20 s |
| HE 额外 EEG 对象/版本分组 | 2/3 | 3/3 | 5/6 | 11 | 18,220 | 13.89 s |

唯一错例是开发 N-short 第一问：预期 A 连续 alpha `2.00e-10 V²`。F/S 直接答，H 读取后答；HE 选对 `N-short-t1`，却把空 `completed_index` 解释成“任务尚未执行”，尽管该任务在 `working_tasks` 中有读取入口。这是**表示/模型读取错误**，不是检索目标错、工具执行失败或历史缺失；单例不能证明额外分组字段是因果来源。其余 23 个答复选对目标且数值、条件匹配 oracle。中链旧版 A cue 有效 Epoch 数 3；B target 事件后 0–1 s、2 个 Epoch 的 SYNTH-C1 alpha 约 `1.682856e-10 V²`。长链 A 连续 alpha 旧/新窗口分别 `2.00e-10` / `3.92e-10 V²`，没有混用版本。

按历史长度：短链 H/F 为 3,719/2,801 tokens，中链 7,470/7,185，长链 6,952/9,045。总六问 H 比 F 少 890 tokens（约 4.7%），但 completion 加倍，延迟更高；S 全部完成且正确，成本与 F 接近。长链压缩可能有价值，但只有一个 10 任务脚本与两问，不构成规模化或统计结论。HE 相对 H 无正确性增量、上下文更长，且多一处误读；四臂共同的 EEG 证据守卫不能记作 HE 贡献。

## 有限自然语言闭环及一次公共接口修正

预冻结 N-short：F/H 各从零按自然语言完成 A 连续功率 → A 幅值 → 切 B 并计算连续功率 → 回问 A alpha。首次沿用旧 `live_turn_v3` 的 `history` 动作，F 即使上下文已有原始数值也被强制读一次；两臂均 4/4 正确、各 5 completion，但这个接口**不能公平比较读取成本**。首次原始结果保留。

唯一执行接口修正：前三轮仍走原 Agent 公共动作及真实 Executor，最后追问改用主配对已冻结的共同直接答/读取/澄清接口。复核中 F 4/4，末轮直接答；H 4/4，末轮按需读取。F 总计 **4 completion / 6,496 tokens**，H **5 completion / 6,950 tokens**。末轮 A 连续 alpha 经独立 oracle 为 `2.00e-10 V²`，没有错取当前 B 的 `7.94e-11 V²`。这是已见短链开发复核，不能算独立确认或长链自主规划证据；模型采样差异亦不能作严格因果估计。

## 归因、最简方案和判断

1. F 的短/中历史含原值，可以零额外读取直接答。H 的摘要缩小首轮上下文，但必须第二次 completion 恢复原始证据；只在本组长链两问观察到 token 节省，尚不抵消更多调用和延迟。S 是有力对照，6/6 正确且可读旧任务，本阶段**未证明 H 相对成熟摘要的正确性或总成本优势**。
2. 任务 episode、不可变修订、完成后摘要和精确证据按需恢复是现有 Harness 中可运行的能力，但借鉴成熟任务记忆思想，并非完整 HiAgent 复现或全新记忆算法。公共 EEG 来源/作用域/版本校验提供安全边界；其收益没有在本试验中单独消融，不能归给 HE。
3. HE 的独立 EEG 对象/版本分组未证收益。推荐**H＋共享 EEG 证据读取守卫**作为最简保留方案，将 HE 分组从推荐路径暂置；旧代码、失败和假设保留，不再追加分组/关键词特例。本轮没有基于确认结果改动方法或评分。
4. 工作点一仍属**有条件候选**：本轮证实 H 可在这些合成同历史查询上保持 F/S 的科学正确性，并在一个较长历史节省实际 tokens；没有证明跨自然长会话、多任务分布和总延迟的稳定收益，也没有证明 EEG 专有分组相对通用任务记忆的独立算法贡献。下一阶段唯一有价值的检验是预注册更长且自然的有效任务历史，在同等读取权/总预算下重复 H 与强 S 的正确性—成本对比；若继续持平，应将其定位为可靠工程组件，不再强行宣称新记忆方法。
