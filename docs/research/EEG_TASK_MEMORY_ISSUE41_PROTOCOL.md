# Issue #41：精确结果保留与证据读回粒度——付费前冻结协议

日期：2026-10-25。继续 PR #37，旧 H/HE 与 Issue #39/#40 原始成绩不回写。配置与样本为 `config/point1_task_memory_issue41.json`；本文件及配置在真实模型输出前固定。

## 已有成本归因与方法选择

Issue #40 本地追加账本 57 次真实响应的可测 provider 使用量为 prompt 98,045、completion 5,861、总计 103,906 tokens；不把本地字符折算成收费。旧同历史六问 H/F 分别 18,141/19,031 tokens，H 12/F 6 次。开发长链第一问 F 首次 prompt 4,350 tokens，H 首次 2,862、读回后二次 461；中链旧试次数 F 首次 3,373，H 首次 2,015、读回后二次 1,593。原始 journal 未保存逐段 prompt 文本，因此不能精确把 provider tokens 拆到 schema、索引、结果或 trace；可对重新生成的相同上下文单独量 UTF-8 大小。实际工具结果：PSD 118 字节、幅值 104 字节，而 Epoch 摘要约 873–879 字节、事件功率约 761–769 字节（不含约 1–2 kB 证据封套和工具 trace）。小结果一律回读显然有额外调用；全保留大结果则反复传无关数值。

比较两种轻量方案：A 全量结果预览不需回读，但随历史线性增长，事件结果包含大量非目标信息；B 仅查询时按需读取字段，可减少第二次提示大小，却仍需模型先选择并追加一次调用。选择**最小组合**：保留任务科学身份/来源/参数/版本；真实结果 UTF-8 ≤256 字节时在任务卡内原样保留完整精确结果，否则只给真实字段结构索引；大结果可一次最多读取 4 条合法标量路径，必要时共用完整读回。根层字段已有摘要索引，嵌套索引仅列真实结果键；已有来源/参数不重复。阈值依据输出大小而非任务名、gold、未来请求或样本长度；不预取。小结果数值直接来自不可变 TaskEntry；大结果字段索引仅含实际键，不生成答案。

同权公共动作 `answer(task_id, answer)`、`read_full(task_id)`、`read_fields(task_id, field_paths)`、`clarify(question)`，四臂 F（完整历史）、S（普通摘要）、旧 H、新 HC 均可用；F 充分信息时可直接回答。字段路径仅能走真实 `TaskEntry.result` 的字典键/列表整数，最多 4 个标量，仍受共有科学范围守卫约束；缺项、非标量、错记录/条件/窗口/版本返回结构化失败。完整读回仍可用于复杂/不确定请求，不新增 Executor 或数值计算。HC 与旧 H 只在保留/索引表示不同；字段级读回属于所有臂共享的接口，不归 HC 独占收益。离线另比“只保留小结果”与“再开放字段级读回”的大小/恢复行为。

## 预冻结配对与评分

开发四问取旧 N-short/medium/long 已见历史（小 PSD、旧 Epoch 计数、双通道事件功率、旧版本 PSD）；仅用来定位缺陷和至多两轮机制修订。确认四问来自新 C-continuous/C-event：不同任务关系、合成波形缩放、幅值旧/新版、事件双通道 alpha 与真正未指定条件/版本的澄清。确认不能只换标签冒充未见；它是本阶段在付费前固定的新合成脚本，非自然人群泛化。历史由既有 Registry/Executor 完整执行，四臂每个问题从同一快照深拷贝开始，task/artifact ID 相同，查询间无焦点泄漏。gold 和独立原数组 oracle 只在响应后评分。

成功须核对目标任务、记录、连续/事件范围、条件、窗口、修订、来源、单位、全部请求标量和自然语言回答。对 `expect_clarify` 只接受合适澄清，不接受擅选一个条件。错误版本即使数值相同判错；功率写成 V²/Hz、遗漏第二通道或答错条件亦判错。自动数值匹配只是预筛，所有真实回答逐例审查。成本计实际输入/输出/总 tokens、completion 数、延迟、读回次数和返回字节；构建/检索本地耗时另列。冻结后确认不能再调候选或评分。

## 独立预算与闭环

Issue #41 新账本独立上限 96 completion / 240,000 API tokens，不沿用旧阶段余额。每个四臂单元最多 8 次，至少预留 8 次/24k tokens，并保留确认与短闭环空间；若预算不足整单元不启动。开发、修订、确认、闭环、失败尝试都计入，关闭自动重试。臂顺序固定 F→S→H→HC；不要先跑候选再剩余预算补 S。确认后，仅 S 与 HC 在新合成 C-continuous 上做短自然语言建史、修订/切换与最后历史回答；仍用现有 Agent/Executor，若先前任务失败不得 gold 回填。仅合成 EEG 必要元信息与真实工具结果外发；密钥/真实 EEG/权重不外发。本阶段结束后停止，不自动进入新付费轮。
