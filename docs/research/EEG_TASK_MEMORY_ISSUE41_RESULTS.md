## 方法及真实接口

候选 HC 在原 H 的不可变任务 episode、来源/作用域/版本卡和共同读取守卫上增加**查询无关的结果尺寸分级**：真实 `TaskEntry.result` 的紧凑 JSON 若不超过 256 UTF-8 字节，在任务卡原样保留；较大结果只列真实嵌套字段结构，需由模型选择 `read_fields`（每次最多四个有界小字段）或 `read_full`。字段读回包含 task/record/capability、参数、revision、source/source_stage、分析配置、单位、evidence token；不返回完整 trace 或 EEG 数组。阈值不由 gold、case ID、未来问题或诊断类别决定。F/S/H/HC 享有**同一** `answer/read_fields/read_full/clarify` 权限，F 的完整历史可直接回答。

开发首轮之后仅作一次有依据的**公共读取接口**修订：原模型曾在一轮请求两个相关字段读回，而接口只接受恰好一个调用；修订后最多接纳四个并行读请求，逐个执行同一科学守卫，合法证据与被拒版本分别回报。摘要展示的 `SYNTH-C1/alpha` 现可安全解释为实际存在的嵌套字段路径；一个不超过 256 字节、最多 16 个原始标量的短列表也可精确投影。错误路径、非标量大对象、错科学范围仍拒绝。该修订**所有方案共享**，不能算 HC 专享效果；首次失败原样保留，未在开发样本上重新付费刷分。确认集之后只修正评价器对“非 V²/Hz”、幅值语境中的否定单位，以及 `×10⁻¹¹` Unicode 科学计数法的通用解析；没有改模型、方法、Prompt、样本或科学真值。原始评分未覆盖，`--audit-file` 可并列复核。

## 有限真实多轮闭环

预注册 C-continuous 合成历史从零以自然语言经原 Agent/Executor 分别建立 A 原窗口幅值 → B 连续频带功率 → A 幅值窗口修订；随后追问旧 A RMS。S 与 HC 各前三步 3/3 工具完成、末轮答案 1/1 正确，均未错取 B 或新版。S 全闭环 4 次响应 / **6,609 tokens**（1,456+1,665+1,968+1,520），HC 为 4 次 / **6,952 tokens**（1,464+1,732+2,085+1,671）。末轮两者均一次直接回答，没有读回；HC 的小值内联未显示额外效用，反而比 S 多 151 tokens（末轮）与 343 tokens（全闭环）。该初次闭环脚本未记录端到端墙钟，不能杜撰。

审查 Issue 原文时发现上述预注册闭环遗漏了**事件对象**。主四题确认结束后，固定补充 C-event 的三步自然语言链 A oddball 事件功率 → 切 B 计数 flash 有效试次 → B flash 事件功率 → 追问 B flash 两通道 alpha。这是透明标注的**协议后集成补充**，不能混入主确认分数或称独立预注册。S/HC 都是分析 3/3、历史回答 1/1 正确，结果与独立 oracle 同为 `9.977652406546746e-11` 和 `4.509943356451858e-26 V²`。S **4 次 / 8,289 tokens / 0 读回字节 / 5.04 s**，末轮直接答；HC **5 次 / 8,852 tokens / 3,406 读回字节 / 5.13 s**，末轮选择完整读回而不是字段投影。这一真实失败边界表明：字段级入口存在不等于模型会用，也不能强迫 S 额外读回制造 HC 优势。两条闭环均仅各一次采样，历史由各臂自身建立，不用于严格同历史因果比较。

离线机制消融只比较**真实字节与合法恢复能力**，不替代模型总成本：C-continuous 小幅值结果原始 96 字节、HC 完整保留视图 135 字节，若不保留则完整证据读回约 706 字节并可能追加一次 completion；C-event 大结果原始 728 字节、字段索引 202 字节，若要两通道 alpha，字段读回 686 字节，完整读回约 3,407 字节。简单“只保留小结果＋大结果完整读回”就能解决小值问题；额外字段接口主要减少**实际发生读回时**的返回量。确认配对与补充闭环都显示 S 常能直接答、HC 有时仍选完整读，因此不能从这组离线字节量推出净 token/延迟优势。

## 失败归因、机制价值与最简保留

1. **明确收益**：小结果内联让 HC 在确认两道幅值历史题直答，旧 H 一错、一需回读；大结果字段级读回让同历史事件双通道题相对 H 缩小返回量约 80%。这证明可运行的结果保留/粒度读取行为，不等于证明其独立算法优势。S 在同题也全部正确，其中一题甚至可不读事件数值；补充事件闭环的 HC 则选了完整读回。HC 对 S 的真实总成本增量很小且延迟更差。
2. **真实代价**：内联扩大任务卡；字段索引和读取接口也占 prompt；大结果若模型仍选完整读、或需要第二次响应，压缩可被额外调用抵消。首次 H 字段路径误用与首次 HC 多读被拒是公共读口设计缺陷，不能误算作 EEG 记忆检索错误。F 的歧义回答是动作/交付策略问题，不是证据未找到。
3. **推荐的最简实现**：保留现有不可变任务历史与来源/作用域/版本守卫，采用**小型真实精确结果内联＋较大结果的简短字段索引＋共用完整读回兜底**；字段级读回保留为可选、所有策略共享的省字节接口，不把它和额外 EEG 分组（HE）捆绑，也不强制模型先读。若目标是当前短/中真实使用的默认成本，强 S 仍是可靠且更简单的参照；HC 暂作为 opt-in 候选，不宜取代 S 或宣称 EEG-specific 创新。
4. **论文判断**：本轮确实定位并缓解旧 H 的“小结果回读”瓶颈，但只在四个新合成确认问和一条闭环上观察到局部效用。相对成熟任务记忆＋强通用摘要，未证稳定的完整答案正确性、provider tokens、调用数、延迟同时占优；“EEG 对象/版本组织”的额外独立价值仍未证。没有启动新方向或第二工作点。继续研究若获新预算，唯一有意义的扩展是预注册更多自然、有效 EEG 历史，在**同一摘要权限及模型条件**下测试小结果内联是否在长会话稳定改善正确性—总成本；若仍持平，应定位为可复用工程策略。
