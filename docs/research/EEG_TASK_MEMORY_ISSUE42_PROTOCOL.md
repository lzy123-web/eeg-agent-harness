## 方法和最小实现

用户当轮自然语言 → 公共 `submit_memory_action`（分析/切换/修订/澄清）→ 既有 `run_instances`、ToolRegistry 与 Executor → 不可变 EEG 任务条目及实际证据 → 当前任务详情、完成任务摘要、结果视图 → 公共 `submit_evidence_action`（直接回答/读字段/读完整/澄清）→ 有来源的回答。修订添加新条目并链接父项，不覆盖旧数值。所有策略使用同一合成记录、任务存储、工具目录、LLM、科学范围守卫和证据读取权限；只有工作上下文表示不同。

- F：完整历史，强参考；可直接回答，不强迫读回。
- S：最近三项完整卡、早期通用摘要索引，保留记录、时间、事件、来源、版本和公共读取 ID；**强主对照**，不是弱化的自然语言聊天摘要。
- HC：HiAgent 启发的任务块/归档与按需恢复；小型精确结果内联、较大结果字段索引；不增加 HE 分组。当前**候选**。旧 H 仅作既有机制诊断，非本轮主配对臂。

HiAgent 的子目标分块、完成后压缩和恢复是成熟思想；LongMemEval 的索引—检索—读取是评价与系统拆分依据。具体 EEG 适配为实际记录、连续窗或事件条件、采样来源、参数版本及单位与证据同存，读回时检查显式科学范围。本项目**未**复现 HiAgent 的 LLM 子目标生成和逐工具主动摘要，也没有新 EEG 数值算法或跨进程记忆库。HC 的按大小表示属于工程成本策略，其独立研究增量须由完整任务实验支持，不因名称而成立。

完整比较请求可同时提及互斥记录、窗口或事件标签，旧单目标读回校验会误拒。公共读取动作现在允许附用户原句的 `scope_quote`，要求是原样子串，且保留该读所属的显式记录、事件/连续类型、窗口或版本限定；再运行旧科学范围守卫。该公共接口修复同权给 F/S/HC，不能记为 HC 独特收益；任意缩短为“alpha”或相反对象会拒绝。模型不得看到离线正确 task_id。

## 数据与工作流

全为已有确定性合成 EEG，经真实 Registry/Executor 运行；A/B 有不同缩放及事件标签，外部只发送任务元数据、必要工具证据，不发送波形。独立 oracle 从原样本按 RMS 或 Welch 积分重新计算，与 ToolResult 比较；不以模型输出作真值。真实数据、私人来源和权重都不进入本协议。

| 分组 | 完整用户目的 | 有效步骤及中途历史用途 | 不应发生 |
|---|---|---|---|
| 开发 D-short | A 的一段幅值测量并追问 | 1 个真实分析、1 个历史回答；检验简单策略是否已足够 | 不补无关历史 |
| 确认 C-continuous | 两记录同窗幅值比较，随后修订 A 窗并回顾旧/新 | A 0–2 → B 0–2 → 中途比较 → A 3–5 新版本 → B 3–5 对照 → 四项比较；第 4 项使早期证据归档，历史须支持参数修订与结果归因 | 旧结果覆盖、A/B 混用、重新计算旧结果 |
| 确认 C-mixed | 区分 A 的事件与连续功率，并与 B 的另一事件条件比较 | A pulse Epoch 功率 → A 同条件有效试次数 → A 连续 PSD → 中途按作用域比较 → B click Epoch 功率 → 跨记录事件结果加试次数比较；第 4 项使早期证据归档 | 将连续 0–2 s 与事件后 0–1 s 混成一类；把 B 条件借给 A |

新确认话语及参数完整固定于配置。每一步是分析目标所需，不为测试故意追加聊天。无临床诊断，不宣称任意开放语言、多数据集或长期病程泛化。短任务预期 F/S 往往更简洁，HC 不必胜。

## 冻结评价与公平性

两条证据层：①从同一真实工具快照，在第一个历史比较处 F/S/HC 分别读取并回答；②每臂从自然语言独立建史，连续到末轮，包含实际修订/追问。①隔离记忆使用，②衡量完整 Harness 效用；首轮工具能力或参数误选导致的历史缺失只能记公共动作/执行失败，不反推为检索差。相同历史取快照，不将离线 target key/task_id/数值传给模型。配对顺序在调用前固定：D-short `S→HC→F`，C-continuous `S→HC→F`，C-mixed `HC→F→S`。

逐轮记录科学正确性与协议动作合规两轴。分析轮的公共返回是实际 ToolResult（不另付费生成一段重复的自然语言答复）；历史比较轮产生最终自然语言回答。科学初筛：真正的记录/能力/参数/修订父项、来源和独立 oracle、答案的数值与单位、被实际展示或成功读回的证据；同一完整任务所有关键轮通过才算严格全达成。协议轴记动作类型；若明确列出候选而未擅选，不等于凭空唯一回答。历史答复还需人工复核数值归属、条件/范围、版本、单位和不确定性，自动数值匹配只是初筛。首轮错误、历史缺失、证据定位、读回、模型读错、答复歪曲分开归因。记录实际 input/output/总 tokens、请求数、读回字节、墙钟时延、本地选择与写入开销；失败不因省 token 被记效率胜利。

预期接受判据：在**同等完整任务科学正确性**下若 HC 对 S 于两个结构不同确认任务反复降低完整总 tokens、额外调用/延迟可解释，则可保留为可选成本机制；若仅同效同成本或更慢，推荐 S 为默认，HC 为可选工程。小样本仅示范与失败归因，不作统计非劣、泛化或临床结论。完整历史 F 是强参考，不人为迫使其多读一次。不会依据 gold 或未来问题预取。

## 预算、锁定与停线

本轮独立上限 **96 external completion / 240,000 API tokens**，append-only 忽略目录 `artifacts/point1_task_memory/issue42/budget.jsonl` 在网络请求前保守预留，自动重试禁用；旧阶段余额不叠加。输出上限每次 900 tokens，先运行无付费离线 oracle/Fake，再开发 D-short；只有公共接口确有实证缺陷时进行最多一次有依据修订，保留首次失败。之后锁定代码/配置，才开始两条确认各 F/S/HC 的完整配对及同历史读取；余额不足时只运行能完整配对的任务单元，不只截断 S。任何确认后必要修订须将相关结果降为开发并留痕。额度是上限不是消耗目标。

复现命令（`eegagent` 环境，PowerShell）：`$env:PYTHONPATH='src'; python -m eeg_harness.research.task_memory_issue42 --offline`；无付费测试 `python -m unittest tests.test_task_memory_issue42 -v`；真实开发/确认须先仅在当前进程加载本地私有 API 凭据，再显式加 `--phase development|confirmation --enable-paid-issue42`。无配置时不得报告真实模型成功。原始响应和完整逐轮私有输出留在 Git 忽略目录；公开只放脱敏、合成汇总。
