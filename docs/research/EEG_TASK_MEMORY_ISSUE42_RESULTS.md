# Issue #42：任务上下文方法定型与完整任务验收

日期：2026-10-26。方法与自然语言工作流在真实模型输出前冻结，见 [冻结协议](EEG_TASK_MEMORY_ISSUE42_PROTOCOL.md)。基于 Draft PR #37；不覆盖 Issue #39–#41 的结果和旧 H/HC 实现。

## 运行完整性与计费

使用既有 `run_instances` → ToolRegistry/Executor 在两份确定性**合成** EEG 上产生真实幅值、连续 PSD、事件窗功率及有效试次数，独立 oracle 从原始合成采样重算 RMS/Welch 积分/事件计数。`--offline` 三条流程全部通过。无真实受试者 EEG、波形、权重、密钥进入外部请求或 Git。

环境：`eegagent` Conda Python；请求 `deepseek-chat`，52/52 个有效响应实际报告 `deepseek-flash`；自动重试关闭。Issue #42 独立账本 **52 completion / 98,029 reported tokens**（input 87,785，output 10,244；0 failed，0 unresolved），低于 96 / 240,000 上限。不叠加旧阶段预算。开发 D-short 6 calls / 7,572 tokens；确认两条完整工作流与各自同历史读取共 46 calls / 90,457 tokens。预算未用完不作为继续试错理由。

原始响应、按轮输出与 append-only 预算账本仅保留在 Git 忽略的 `artifacts/point1_task_memory/issue42/`。确认原始输出 SHA-256：`152347da2f92547ca8e0901ab28e69ce440d30bcc434bbbff66e7493d4c43f8c`。本报告只引用脱敏的合成结果摘要，不公开私人环境或凭据。

## 方法到底是什么

任务目标由自然语言与当前元数据决定；执行结果写入不可变 `TaskEntry`，以记录别名、真实来源、能力、参数、修订父项、单位与证据 token 绑定。活动任务保留操作与错误，完成任务保存紧凑摘要；工作上下文可选完整历史 F、强摘要 S 或候选 HC（小真实结果内联，大结果字段索引），所有臂可直接作答、读字段、读完整原始证据或澄清，显式科学范围不匹配由共同接口拒绝。新分析继续走原 EEG Executor，不由历史读取暗中重算。完整比较请求的公共 `scope_quote` 只允许引用用户话语的真实局部范围，不使用离线目标 ID。

任务块/完成后压缩/按需恢复借鉴 HiAgent；索引—检索—读取及时间版本问题拆分受 LongMemEval 启发。记录、事件或连续时间语义、参数修订、来源和单位与真实工具证据同存是 EEG Harness 的领域适配；现有材料**不证明** HC 是新的通用记忆算法，也未复现 HiAgent 的自主子目标分解或逐工具主动摘要。

## 配对结果：完整自然语言流程

下表为完整分析→中途历史比较→后续分析/修订→最终历史回答的**逐轮自动初筛**；“修订后”只指评分器逗号拆句修正，不是模型或候选方法修订。所有臂看到同一冻结话语/工具权限，在各自会话内独立建史；`S` 的时间/版本信息和读取权限未削弱。

|---|---|---:|---:|---:|---:|---:|---:|
| C-continuous，6 轮 | F 完整历史 | 5/6 | **6/6** | 6 | 10,368 | 7,694 | 0 |
| C-continuous，6 轮 | S 强摘要 | 4/6 | **6/6** | 7 | 11,664 | 9,668 | 1,805 |
| C-continuous，6 轮 | HC 候选 | 4/6 | **6/6** | 6 | 11,108 | 8,415 | 0 |
| C-mixed，6 轮 | F 完整历史 | 3/6 | **3/6** | 6 | 12,442 | 8,089 | 0 |
| C-mixed，6 轮 | S 强摘要 | 4/6 | **4/6** | 6 | 13,681 | 6,443 | 0 |
| C-mixed，6 轮 | HC 候选 | 5/6 | **5/6** | 8 | 19,569 | 13,324 | 10,797 |

C-continuous 四次真实幅值分析、A 的旧/新窗口版本与 B 的两个窗口均正确，最终比较明确标出记录、版本、窗口和 V。S 在最终轮选择读四个真实字段；F/HC 的精确值已可见而直接回答。HC 对 S 在此流程节省 **556 tokens（4.8%）和 1 次调用**，但 F 更低成本。这个单例不足以声称重复收益或统计优势。

本地成本补测（同一四任务快照、每种操作 30 次取中位数、无模型请求）：C-continuous 的 F/S/H/HC 上下文选择分别约 0.080/0.065/0.327/0.336 ms，C-mixed 约 0.244/0.148/0.518/0.584 ms；四条任务摘要的共同生成分别约 0.0026/0.0034 ms。因测量只包含摘要生成和选择/序列化，不包含原工具计算、完整写入或磁盘 I/O，不能据此声称完整存储成本更低。实验轮次的实际墙钟已在上表计入；本地选择开销在本规模远小于外部模型调用，但 HC 高于 S。复现：`python -m eeg_harness.research.task_memory_issue42 --offline-cost`。

C-mixed 四个真实分析产生事件功率、有效试次数、连续功率与另一记录事件功率，S/HC 的四项分析均正确，F 在第二步把 `epoch_summary` 错选为对 `event_bandpower` 的 `revise`，原执行器拒绝，故缺少独立计数条目；后续答案虽能从事件功率结果看到试次数，不抹掉此前操作失败。HC 中途只读到事件功率，把连续功率误判为没有可用读回证据并安全省略，最终跨记录事件比较及 A 的 3 个有效试次答对。S 中途对卡片的 `result_preview` 路径误当底层结果路径，读取失败；末轮模型给了非原文范围引文，公共安全守卫拒绝。F 中途也误用 `result_preview` 字段路径；末轮从可见条目给出数值，但原任务要求的独立计数分析并未执行。HC 比 S 多 **5,888 tokens、2 次调用、6,881 ms 与 10,797 字节读回**，且中途未完整完成，不能以末轮答对宣称更有效。

## 同一实际历史的读取隔离

每臂从相同真实工具快照出发，排除首轮能力误选和缺失历史。C-continuous 第一次跨记录幅值比较：F/S/HC 均 1/1，均直接回答，分别 1,326/1,386/1,445 tokens；压缩无可见效用。C-mixed 事件与连续功率的中途比较：自动严格初筛 F/S/HC 均 0/1。F 的回答按段列出两个正确数值及不同时间基准，人工核验科学数值与条件正确，但用了“**两次读取都已完成**”的错误过程措辞（实际上直接从可见证据回答），因此不升级为严格完全正确。S 仍误读字段路径；HC 读了有效试次数而不是连续功率。这表明相同历史下仍有证据使用失败，不可全部归因于先前任务未建立。三臂分别 2,549/2,277/2,642 tokens、1/1/2 calls；HC 多读并更慢。

## 评分器追加审计与逐类失败

首次评分器把中文逗号也当记录—数值句界，错误地把“记录 A，SYNTH-C1，0–2 s：RMS = …”判作数值无来源；表格多列同样受到影响。保留原始 `rows[].score`，仅用统一的“分号、句号和换行才断句”规则重新审计；独立正例和 A/B 对调负例均通过测试。该修复**不修改用户请求、oracle、模型响应、任何臂的上下文或成绩原件**。即便追加审计，长段标题与下一行数值的绑定仍可能误拒，故自动初筛并非 EEG 专家人工标注。

| 类型 | 真实观察 | 归因 |
|---|---|---|
| 公共动作误选 | F 将有效试次数分析误作跨能力 `revise`，执行器返回 `INVALID_REVISION_PARENT` | 通用自然语言动作/能力理解，不是记忆定位 |
| 证据 API 表示不一致 | F/S 将卡片 `result_preview` 前缀复制进底层 `read_fields` 路径，返回 `FIELD_NOT_FOUND` | 公共字段路径接口可用性；S/HC 权限未区别 |
| 候选证据选择不足 | HC 中途读 event_bandpower 和 epoch_summary，却没拿到所问的连续 PSD | 工作上下文/读取决策不足；未编造数值 |
| 安全拒绝与可用性冲突 | S 末轮 `scope_quote` 非用户原文子串，得到 `INVALID_SCOPE_QUOTE` | 公共范围守卫安全拒绝，合法任务误拒待处理 |
| 自动评价误拒 | 连续答案中的中文逗号/Markdown 表格；事件答案段标题—数值跨行 | 评分器结构问题，原件不变，透明追加审计 |
| 证据过程措辞 | F 同历史事件回答称已完成两次读取，但真实是直接看可见值 | 科学数值正确，证据过程叙述不忠实 |

## 贡献—证据—限制与收敛判断

| 主张/组成 | 实现 | 本轮证据 | 可接受结论与限制 |
|---|---|---|---|
| 真实 EEG 任务不可变历史、修订与来源绑定 | 公共 `TaskEntry` / `EpisodeMemorySession` | 连续 6/6 三臂均完成，旧版保留；事件样例均产生真实工具结果 | 是可用 Harness 基础；非 HC 独占创新 |
| 完成任务摘要与按需恢复 | S、H、HC 均可访问底层证据 | 四项有效分析后归档确实触发；S 有一次字段读回，HC 有事件完整读回 | 成熟记忆思想的领域应用；模型读取仍不稳 |
| 小结果保留、大结果索引 HC | `result_view` + 通用读字段 | 连续比 S 略省，但混合任务明显更多 tokens/调用/读回且漏掉中途目标 | **不足以证明可重复成本或正确性增益**，不作为必选默认 |
| 科学作用域/版本读回守卫 | 全臂共享 `scientific_read_mismatch` 与比较引文 | 错对象和非原文引用拒绝，未凭空生成未读功率 | 安全工程边界；也可能误拒，开放表达覆盖未证 |
| 优于强 S 的论文方法贡献 | 预期 HC 在完整任务保持正确且降低总成本 | 两类确认只一类同效略省，另一类更贵且不完整 | **当前证据不成立**；不得声称统计优势、泛化或临床适用 |

**推荐的最简实现**：保留公共任务级不可变历史、显式版本/来源、科学读回守卫和强 S 作为默认；F 用于短会话或成本不敏感的完整审计；HC 保留 opt-in、仅当真实结果体积/负载有明确收益时选用，不按 case ID 切换。HE 额外 EEG 分组继续暂置。对于只有 1–2 个任务的短查询，复杂压缩没有价值；对于事件与连续证据并置的任务，先解决公共字段接口和证据选择可靠性，再讨论 HC 性能。

工作点一的研究对象可以明确表述为“多轮 EEG 分析中任务、参数版本、科学作用域与真实证据的上下文组织和安全读回”，但本次没有证明其相对成熟强任务摘要的**独立方法增量**。下一阶段唯一值得做的动作是与导师审查这一贡献定位和实验结论，决定是否将任务记忆保留为 Harness 工程组成部分；不继续为 HC 刷阈值、小样本或长历史，不自动启动第二工作点。
