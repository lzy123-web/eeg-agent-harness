## 问题、选项与决定

旧 `history_turn` 首轮上下文可有精确数值，读回后末轮却仅含 `reads`；旧评分以“首轮可见∪读回成功”估计可用，未检查末轮输入。离线回归要捕获两次实际 messages 证明，而非把静态推断写成真实模型失败因果。对比三种最小选项：①重发完整首轮上下文，简单但可能重复全部历史及轨迹；②只发新读回，当前缺口；③构造有界本轮证据集合。选③：从首轮实际展示的精确结果和经科学范围校验的成功读取形成统一可引用集合；卡片索引不能成数值。每项保留 task_id、source、record、capability、parameters、revision_of、unit、evidence_token、字段路径与真实值；同任务同路径去重，矛盾显式失败。只带首轮选中任务的精确结果，不重发 full_messages/tool_trace；若容量上限无法无损保留则安全澄清，不默默裁剪。

公共展示和读取均使用相对于 `TaskEntry.result` 的规范化字段路径。多对象读取以结构化 `scope` 绑定请求中明确的记录、连续/事件、条件、窗口及版本，检查原请求与真实任务；不要求逐字引用。错误对象、缺失路径、无记录、旧/新版本混淆与不充分绑定需拒绝或澄清。开放自然语言理解不保证覆盖任意表达。

## 验证层次与预定任务

1. 离线消息级复现及 Fake 回归：两值直接可见；可见＋读回；两次读回；字段部分成功；错误＋成功；重复读取；A/B、连续/事件、版本与歧义。断言最终 messages 中的**值及来源/范围/版本**，分别统计存储、首轮可见、读回成功、最终实际可见。Fake 不证明真实理解。先用旧 C-mixed 复现，算已见开发资料。
2. 开发同历史旧/新交接配对：旧 C-mixed 的合成真实工具历史；仅为缺陷因果诊断，旧成绩不改。预算内有限真实模型验证，新旧共享相同请求及历史；如果用不同采样输出，只称观察，不称严格因果。
3. 新确认 N-continuous（连续 PSD、A 修订、跨记录版本比较）与 N-mixed（A 事件计数、B 事件功率、A 连续 RMS、A 事件功率，四目标交付），配置中的请求/参数/目标在确认前冻结。两条都从自然语言分析、真实 Registry/Executor 建史到最终历史回答；S/HC 主配对，F 强参考。每臂独立建史，不以离线目标 ID 补齐失败。顺序 N-continuous `S→HC→F`、N-mixed `HC→F→S`。脚本按 `turn.kind` 给定分析/历史交互类型，这是受控链路验收，不宣称任意自然语言统一路由。

所有数值从合成原采样独立 oracle 核验：RMS 为 V；绝对频带功率为 V²；试次数无物理单位。工具值与 oracle `rel_tol=5e-3, abs_tol=5e-13`；答案数值宽松初筛 `rel_tol=0.05`，之后逐例人工审查绑定/方向/单位/过程措辞。必须区别完整、部分、正确澄清、不必要误拒和错误；分析轮科学执行与动作类型分轴。回答证据只按**最后生成输入**及直接回答首轮输入评分，不能依据隐藏的 TaskEntry 追认支持。开发旧案例及确认首次失败都留存，不改科学真值或按结果改提示。

记录调用/输入输出/总 tokens、墙钟、读回字节和本地选取/交接耗时；同一历史可用于局部交接因果，完整闭环的不同历史不能直接作纯记忆因果。公开结果只给脱敏合成逐例清单和成本。自动初筛需用负例审计多行/表格、中文标点、科学计数法、否定单位、A/B 交换、同值异范围、计数和功率混合，人工审阅的范围单列。
