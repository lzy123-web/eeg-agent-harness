## 实现与反例

旧路由的离线消息级反例：C-mixed 的 HC 首轮真实卡展示连续 PSD `SYNTH-C1.alpha=3.33e-10 V²`，模型读取另一项事件功率后，末轮 user message 只有 `request+reads`，没有连续值；旧评分却可能因首轮可见而记 `evidence_available=true`。这是接口缺口的**消息级因果复现**，不是宣称某个旧 DeepSeek 失败必由此引起。修订后 `task_memory_evidence.py` 只从首轮**实际展示**的精确卡和经校验的 `read_full/read_fields` 构造本轮有界证据集合；按 `(task_id, path)` 去重，保留 `record/source/source_stage/parameters/revision_of/unit/evidence_token` 与 `via`。索引、未执行任务、失败读口和冲突值不成为数值。最终回答调用只收到此集合及失败码，不重发完整消息历史或工具轨迹；超过 8 任务/24 KB 安全澄清，不静默截断。

任务卡 `readable_fields` 由真实 `TaskEntry.result` 的规范路径生成，读取仍由原 Session 限制为任务结果内的标量；合法显示包装路径可规范化。结构化 `scope` 将多对象请求中每次读取的记录、连续/事件、条件、通道、窗口、版本绑定到用户当轮请求和真实任务。旧逐字 `scope_quote` 入口保留用于旧结果复现，新公共入口不依赖逐字抄写。F/S/HC **同权使用**新契约，不计作 HC 独有创新。分析仍走原 `run_instances`→Registry/Executor；脚本预先给定轮次的 `analysis/history` 类型，不能宣称任意自然语言统一路由。

```text
实际分析 → 不可变 TaskEntry(记录/范围/版本/来源/结果/trace)
       → F/S/HC 选择当轮任务卡（仅表示不同）
       → 模型直接 answer 或提交 ≤4 次 read
       → 公共范围校验 + 真实任务结果读取
       → exact(first-visible) ∪ exact(valid reads)，按任务+路径去重
       → 仅把该有界集合及失败码交给末轮模型 → 完整/部分/澄清回答
```

离线覆盖两值直接可见、一可见＋一读回、两对象读取、部分字段、成功＋失败、跨 A/B、事件/连续、旧新版本、重复读取、错误记录/条件/通道/窗口/版本及未执行任务。`--offline` 在真实 Registry/Executor 上新执行 N-continuous 的 3 项分析和 N-mixed 的 4 项分析；RMS、Welch 积分、事件有效试次数由合成原数组独立 oracle 核验。Fake 只断言实际末轮 messages 中的值/来源/范围/版本，不冒充语言理解效果。

## 已见开发诊断（不是新确认）

使用旧 C-mixed 同一真实历史问句，小型 DeepSeek 旧/新配对：旧 S 直接答两项，旧 HC 读事件后仅答事件；新 S/HC 末轮均实际收到首轮连续值和新读事件值，两项数值都写出。旧/新不同采样，不将回答差异称为严格因果收益；离线同动作消息对比才证明交接机制修复。开发累计 7 completion / 16,330 tokens。

首次新路径发现两项公共缺陷并在确认前修订：①给连续读回构造守卫文本时误附另一目标的事件标签，引起合法读取拒绝；②自动评分按单行拆开标题和后续数值，误判来源。原始开发输出/分数保留，修订评分仅追加审计。开发模型还曾把 `read_fields` 数值误说成“首次可见”，记为过程措辞错误，不因数值对而掩盖。

## 成本、评价器与研究取舍

阶段独立账本 **37/80 external completion、82,393/180,000 API tokens**（输入 73,410、输出 8,983；0 网络失败、0 未结算）。开发 7/16,330，确认 30/66,063。请求 `deepseek-chat`，37/37 响应报告 `deepseek-flash`。最后一轮证据交接 JSON 为 N-mixed HC/F/S 约 1,317/8,227/5,706 UTF-8 字节；本地合并耗时约 0.17/1.14/0.43 ms，尚未包括完整任务执行、日志 I/O 或服务耗时。仅按正确性和成本的这个样本，HC 没有优于强 S 的证据；F 在混合任务正确但 tokens 最多，短连续任务三臂成本接近。不同响应与时间不能作显著性或算法净收益推断，不为用完额度追加请求。

自动评估在模型输出后仍需透明审计：段落标题/表格行、中文标点、科学计数法、否定单位、A/B 交换、同值异范围和计数/功率分离均有离线正负回归；确认原 `rows[].score` 不覆盖。追加 `--audit-file` 仅列同科学对象的计数替代证据与当前解析结果，仍标注人工审阅必需。原严格数字屏查不能捕获 HC 的 B 版本误述，也不能把 S 的合法替代来源自动算完整；过程措辞、科学结论和动作合规保持分轴。

**收敛**：保留不可变任务历史、真实来源/范围/版本、规范字段读口、末轮显式证据集合及科学拒绝；这是可用的任务上下文管理链。S 作为简单默认，HC 保留可选研究对照，HE 不继续扩展；F 适合短历史或完整审计，但长结果成本可能高。任务块、摘要和按需读取借鉴成熟 HiAgent/记忆方法；EEG 来源、事件相对时间与连续时间、版本/单位的绑定是领域适配。公共交接修复是必要工程正确性，不是 HC 独立贡献。当前**未证实** HC 相对强 S 的稳定完整交付或净成本优势、开放语言科学范围理解、真实受试者/多数据集有效性，更不能宣称临床用途或第二工作点。下一步应由导师评估将该路线定位为 Harness 关键工程方法还是需要新的、预先可证伪的 EEG-specific 增量；本阶段按 Issue #43 停止，不自动开新收费实验。
