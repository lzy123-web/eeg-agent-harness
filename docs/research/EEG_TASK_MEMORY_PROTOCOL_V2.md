# PR #37 审查后补充协议 v2：有判别力的离线多轮历史

本协议是对 `point1_task_memory_protocol_v1.json` 的**追加开发诊断**，不是改写旧协议或旧 DeepSeek 结果。机器可读脚本 `config/point1_task_memory_protocol_v2.json` 在 v2 选择器实施与运行前冻结。依据 [PR #37 阶段审查](https://github.com/lzy123-web/eeg-agent-harness/pull/37#issuecomment-6395350899)，先验证上下文机制是否真正工作，本轮外部模型调用为 **0**。

## 任务历史与公平性

三条会话分别有 3、6、10 个**真实执行的有效 EEG 分析任务**，不是无关干扰文本。内容涵盖连续 PSD/幅值、事件试次数/事件窗功率、记录 A/B 切换、参数修订及历史追问。事件标签 `cue/rest/target/standard` 仅是合成数据元信息，通过真实 `EventSet` 注入，不写在检索代码里。所有任务由同一个 `MultiTurnEEGSession`→v3→Registry/Executor 执行；所有方案在同一任务历史前缀上检索。设计者事先写明每个查询的目标任务键和要读取的数值字段，**目标键仅评分器可见**。同一合成原始数据与实际结果构成 oracle，不让记忆模型生成自己的真值。

F：全部历史、消息和真实结果，不截断。S：最近 3 条完整任务卡 + 更早任务的通用任务摘要索引；索引保留记录、能力、参数、顺序、修订关系、结果读取入口与可用结果字段，不抹去数值证据。G：相同任务块与原始结果，通用词面/字段、记录、通用时间窗、序列与版本关系检索；**旧/新版本关系对 G/E 相同开放**。E：在 G 的通用能力上增加从实际任务参数、记录通道与事件元信息得出的 EEG 科学对象/作用域一致性排序。E 不独享 gold、查询重写模型、证据读取工具或更大 top-k。`E−science` 消融只移除 EEG 作用域附加排序。所有压缩臂用最近 3 条完整卡/检索 top-3；6、10 条历史必然触发真实选择/摘要，3 条短会话作为“无需压缩时”强参考。

先运行**相同历史前缀离线回放**：逐查询记录可见任务卡、摘要触发、目标 top-k/top-1、`read_task` 的真实记录/能力/连续或事件范围/修订祖先/来源/字段数值、上下文字符和 token 代理。数值比较使用独立原始信号的 NumPy/SciPy oracle，容差 `rtol=5e-3, atol=5e-13`；同一 task ID 但科学条件或结果错误必须判错。F/S 的展示顺序不作为排名算法胜负；S 摘要中的历史 ID 可调用**同一**只读结果接口。

单独审计公共动作接口：空历史 `analyze` 与纯导航 `switch` 的错误独立分类；后续分析/澄清/历史读取分别评分。历史缺失引起的级联失败保留，但不能算作检索器错误。冻结旧 v1 实验和真实响应，不事后改写其分数。当前 v2 脚本由研究者设计，不是自然用户语料，也不是新的 untouched holdout；不能由离线检索指标推断真实 Agent 成功率或论文优势。

## 先验停止线与后续真实配对清单

只有确认中/长历史实际触发压缩和 top-3 选择、语义评分器可区别同 ID/错 scope/错版本/错数值、F/S/G/E 获得同等可见证据之后，才考虑申请**新的独立预算**做真实闭环。建议最小配对：中会话 3 个、长会话 5 个历史追问 × F/S/G/E（32 决策调用）；若交付最终答案，每轮再 1 次模型调用（另 32），总上限 64 completions，建议 token 上限 140,000，另预留不超过 8 次公共接口故障重试并逐次计费（绝对上限 72 completions）；真实执行前需冻结新的自然语言交互清单，不能继续在旧 M1/M6 上调参报未见成绩。双方模型、温度、工具、answer 协议和上下文可读原始记忆相同；逐臂记账摘要/检索/读取/回答成本。**此处只是预算与运行计划，不授权本轮付费调用。**
