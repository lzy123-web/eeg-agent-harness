# Issue #36：多轮 EEG 任务上下文实验结果

> 后续 Issue #39 已在同一 Draft PR #37 进行真实四臂闭环、两轮针对性修订与独立确认。旧 Issue #36/#38/v2 的结果均为历史版本、不在本页覆盖；新阶段协议、逐例失败、实际成本和 300,000-token 停线见 [Issue #39 结果](EEG_TASK_MEMORY_ISSUE39_RESULTS.md)。

## 证据等级与复现边界

本报告只使用 6 条研究者预写的合成会话 M1–M6；M1–M4 为开发、M5–M6 为验证。脚本和评分目标先于实现及真实模型输出冻结在 `config/point1_task_memory_protocol_v1.json`，没有外部人工金标。原始响应和逐轮状态仅保留在被 Git 忽略的本地 `artifacts/point1_task_memory/`，不含真实受试者 EEG。以下逐例摘要可公开复核，但**回放、模型决策闭环、模型最终文字回答是三个不同证据层**。

第一次回放 `replay_20261025T074218540864Z.json` 错误地为每臂重新执行工具，导致随机 artifact ID 不同，不能作为“相同历史”比较。修正为每条脚本仅执行一次，再让所有臂读取同一不可变历史；以下仅使用 `replay_20261025T074303171142Z.json`。旧文件保留作审计，不被覆盖。数值验证从合成原始记录独立切片：连续 PSD 与事件窗 alpha 功率均由 SciPy Welch/积分重算，容差 `rtol=5e-3, atol=5e-13`；不同记录、修订前后数值确实不同。

### 失败归因与回答核查

1. M1 初版 G：`absolute=true` 超出已声明的 PSD 参数；公共 Executor 拒绝是正确的。问题在共同模型→能力参数契约，不是历史检索。M1 第一修订两臂过度澄清是共同能力语义描述回归。第二修订改为从 `capability_catalog` 生成两臂共用的用途/作用域/必需与合法字段，不添加针对某个 case ID 的 EEG 记忆规则。
2. M6 最终回答版两臂同错：首轮 `switch B` 没有执行幅值分析，导致后续“同一窗口”“先前 B 的 RMS”没有证据。第三轮实际事件功率输出与工具值吻合，最终回答标明绝对事件窗功率而非 ERD/ERS，未观察到将这一步改写为临床结论；但本轮不能以剩余 2/6 掩盖级联错误。
3. M1 最终版四个旧/新 alpha 历史回答（两臂各二）经逐条对照，任务版本、通道、数值与 `V²` 一致。M6 失败后的最终回答没有虚构缺失的 RMS，正确指出该数值不存在于本臂历史。此为**定点人工核对**，不是覆盖全部长答复的自动事实一致性评价。
4. 相同历史回放中 G/E 均 10/10；真实闭环在修订后 M1/M4 均持平，重复验证 M6 也同败。无法归因出 E 的独立收益。完整历史 F 与摘要 S 未参加付费闭环，因此没有它们的端到端成功率或真实 API 成本；不能把回放覆盖率冒称 F/S 真实 Agent 结果。

## 实现与复现

- `MultiTurnEEGSession` 统一保存真实任务条目、结果与不可变修订关系；两个合成记录各自创建 `ExecutionContext`，一次分析沿用既有 v3/Registry/Executor。`read_task` 是所有臂的同一只读结果接口；记录切换不迁移 artifact。`live_turn` 决策和可选最终回答都用共同协议。
- 无 LLM 回放：`$env:PYTHONPATH='src'; python -m eeg_harness.research.task_memory_eval --mode replay`。有凭据的真实配对例：`python -m eeg_harness.research.task_memory_eval --mode real --sessions M1 --policies G E --max-requests 20 --max-total-tokens 50000 --final-answer`。**本轮 96 次外部调用已满，不应为本报告再执行真实命令。**
- `python -m compileall -q src tests`、`python -m pip check`、`python -m unittest discover -s tests -q` 在 `eegagent` 环境通过；281 tests、15 个资源门控跳过、0 失败，其中新增 9 个定向测试。旧 CIEDG、旧正式实验与主线实现未改。

**限制**：小型、研究者受控合成对话；不同策略并非论文 HiAgent 原实现；S 未充分触发；E 检索依赖有限词面/字段，数据阶段与模型配置虽在证据中但未成为完整索引；模型决策有随机/服务侧变化；无独立自然用户、真实 EEG 数据或临床有效性。本结果只支持原型可运行与具体失败归因，不支持新颖性或泛化优越性主张。
