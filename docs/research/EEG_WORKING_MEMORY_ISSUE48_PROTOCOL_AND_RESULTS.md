## 2. 方案取舍与共同正确性边界

最简单的候选是只在提示中解释字段路径、依赖ID与缺参要求。这可以减少误选，却无法阻止模型自行填窗，也不能使错误完成合同被纠正后保留已产生结果。另一方案是再增加独立规划或验证 Agent，但会扩张研究范围、增加调用和新误差来源。本轮选择原 Store/Controller 上的最小可继续生命周期：**结构检查→科学参数来源核对→待补/执行→实际交付条件核验→归档/修正/续接**。

- 模型提出目的、交付与引用，程序核验当前可表示的原文、已确认结果、工件或配置来源；不能只信 `source=user`。来源检查有明确的语言表达边界，不声称证明任意自然语言语义完备。
- 字段引用合同在能预先检查时提前验证；实际数据不满足条件与表达式错误分开。技术表达修正不能删除必要项、改变阈值或换科学范围来制造完成。
- 缺参保存原目的、已知字段与待补事项，先澄清；后续回答补入同一目的。科学范围改变则产生新版本，旧结果不覆盖。
- 批次仍由原 `EEGAgent.run` 串行执行；每个call_id都有已执行结果或明确未执行原因，逐动作记录归属。不给模型尚未存在的工件ID。
- 新结果已由原逻辑自动关联交付；不再增加一轮“绑定已执行结果”的必要步骤。重复合法绑定应为无变化，不包装成新进展。

这些是所有新版上下文方案共用的科学接口和工程可靠性，不归候选记忆独有创新。HiAgent 的继承仍是按目的组织当前行动—观察、完成摘要与需要时恢复；本轮适配是科学范围/版本/真实交付参加生命周期，并按实际证据减少重复展示。不是完整 HiAgent 原基准复现。

## 3. 冻结协议：四会话八请求

请求、数据定义、资源限制和只供事后核验的标准均在 `config/point1_working_memory_issue48.json`。候选确认前记录实际Commit与该文件SHA-256。开发使用既有A/B合成记录和旧Issue #47结构的连续＋事件请求，明确属于开发回归。确认重新生成不同通道频率混合、分段增益和事件位置，比较关系也改变；并非仅改标签或整体缩放，仍只是小规模阶段确认，不能称全面未见泛化。

确认顺序固定为 **D→C→A→B**。每会话单独保存完整上下文和返回；候选与对照的正式真实排行榜不在本轮运行。

|会话|自然请求用途|必须检查|会话累计硬边界|
|---|---|---|---|
|D：1轮|B的采样率、时长、通道|实际记录元数据、最终完整回答，无不必要复杂控制|6 completion / 30,000 tokens|
|C：2轮|B/target/SYNTH-C2事件theta，先缺事件窗；真实澄清后用户补0～0.75秒|先不进行缺参事件数值分析；补充后仍是原目的、原记录/条件/通道；实际试次数及功率|10 / 70,000|
|A：3轮|A/C1连续0～2秒RMS和alpha；改4～6秒比较旧新alpha；再问最早RMS|多结果交付、版本关系、比较方向及数值、历史精确值不用重算|18 / 120,000|
|B：2轮|B/C1连续1～3秒＋target事件0～0.75秒计数/C2theta；沿用原试次追加质量及C1/C2theta比较|两个任务同入口、原工件续算、无筛选/基线变更、质量未设阈值不猜、过程说明来自真实过程|22 / 130,000|

以上合计56次/350,000 tokens，为完整确认预留；不能把某一会话未用余额临时挪给失败会话刷分。单轮原有24轮/24工具上限不调大。真实请求不包含工具调用名、正确子目标列表、正确ID或顺序；接口说明与实际状态仍可见。C补充必须响应实际发生的相应缺参澄清：结果为clarification_required，待补目的仍绑定B/target/event_bandpower，并明确缺tmin/tmax，且未成功执行任何缺参事件数值动作。通道选择仍由原用户文本保存，事件工具本身输出所有通道。驱动器不因泛泛澄清、错目的或已猜窗先算而暗中补窗；该门槛仅控制模拟用户回复，不进入候选上下文。

### 允许的等价行为与评分

一个或多个子目标均可，只要原需求得到完整交付。原工具可计算全频带/全通道，末轮需给出请求字段；不把输出形式差异当科学错误。直接使用当前有效可见结果合法，不强制调用恢复工具；但未触发恢复时必须单列“自主恢复未验证”。

逐原始请求核对实际记录、通道/条件、绝对/相对窗、参数版本、来源、单位、实际数值及比较关系。计数只代表窗口边界有效，不能解释成未测量的质量合格数。独立oracle由原始合成采样和Welch计算得到，不从ToolResult复制；连续字符串允许rtol=0.005、事件rtol=1e−6，atol=5e−13。单项数值正确、子目标完成或工具API成功不能替代最终完整任务评分。

结果分为完整成功、部分交付、正确澄清、错误拒绝、错误/未完成。失败再区分需求/科学范围、合同与引用、数值执行、任务状态、上下文/恢复、末轮表述及预算/资源。错误单位、未经确认的窗、错版本和臆造阈值均是实质失败。离线受控结果不计入模型自主成功。

恢复证据需串联：实际读取旧过程→进入后续模型请求→被用于同一工件合法续算或有依据的处理说明。单独出现restore动作名不计充分证据。每个结果保存原始ID，不能用同轮reuse替代跨轮过程恢复。
