# 工作点一开题材料：科学交付约束的EEG任务工作记忆

**研究定位。** 面向多任务EEG分析的通用Harness，研究持续分析中的科学任务完成与证据使用。继承成熟Plan-and-Execute、任务级工作记忆和工具校验，不主张发明DAG、结果传递或全新记忆理论；不研究ASD诊断，不开展工作点二。

**普通强P&E已经能做什么。** 模型从自然目标提出依赖任务，局部选择工具，保存结构化结果、来源与参数版本，传递真实工件，发生错误时澄清或重规划，并读取旧结果和过程。它也可以正常区分同一工具的两个时间窗。这里的A基线具有这些能力，自动绑定实际结果而非让模型重复抄写ID；明确科学条件和检查工具不向它隐藏。

**仍值得检验的问题。** 工具运行成功不等于用户要求的科学条件满足；后续分析可能只需要一个字段、一个原工件，也可能需要过去的实际处理过程。让模型自行完成验收与读取，或一律传递完整结果，都合理，但正确性与总成本需要同条件比较。不能把旧控制器的错误说成成熟P&E必然存在的问题。

**本方法具体增加什么。** 第一，以实际结果实例和明确科学验收条件约束节点完成及下游依赖放行，辅助失败只保留为尝试，不自动变成科学欠账。第二，以DAG的真实输入引用选择任务摘要、精确字段/工件或行动—观察过程，并保持统一升级读取；来源、时基、处理版本和工件身份贯穿这些接口。稳定科学任务ID与执行episode分离，历史引用可固定旧版。后两项身份/安全基础三组共享，不能全部归为候选独有增量。

**已实现与已有证据。** 新路径接原Agent/TaskStore/Executor，`run/continue`接受自然请求，正式入口不接gold DAG或预期工具顺序。离线使用明确标注的受控计划，真实数值仍由原工具产生。八类×三臂93项独立数值核验通过；正常任务、修订及原工件续算中A/B/C均可完成。两类自然省略/混合范围仍被共享来源校验保守拒绝，不改请求追分。在故意错误的“实际3试次却宣布满足≥4”完成提议下，C拦截；强P&E取得同一自动检查后也拦截，说明该差异可由通用校验配置消除。过程任务中C受控步骤7次、A/B8次，仅说明指定依赖下的自动过程供给，不代表真实模型节省一次调用。新阶段外部模型调用为0。

**代价与不足。** 需要维护科学结果合同、依赖引用、旧新版本和分层读取，增加公共控制代码、schema及上下文开销；规划遗漏、错误字段、自然语言歧义和最终表达仍可能失败。强P&E若同样可靠且更简单，应采用它，不再增加复杂模块。共享底座的成功不能反证候选独立创新已经成立。

**可准确写入的拟创新表述：**“在既有计划执行与任务级工作记忆基础上，研究面向多任务EEG分析的科学交付与依赖证据协同管理方法，以实际结果及科学条件约束归档和后续使用，按依赖需要提供不同层级的真实证据，并通过同信息、同读权的强基线与消融检验可靠性及成本取舍。”应写成待验证的领域适配主张，不能写“首次提出”“显著优于P&E”或“自主闭环已通过”。

**明确判断与下一步。** 当前足以支撑开题研究方案、方法定义和实现基础，**不足以支撑已成立的独立创新结论**；资格判断为B，缺的是完整真实使用和可归因效用证据。下一步唯一重点是冻结协议下的一组完整三臂真实自然会话，分别核对规划、科学验收、证据使用、最终交付及全部成本。不得把本轮受控开发任务改称未见测试。若合理A或A-equivalent同样可靠且更低成本，就收缩为公共领域适配，采用简单实现，不继续堆机制。
