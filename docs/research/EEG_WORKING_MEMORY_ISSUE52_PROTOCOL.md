## 1. 唯一比较问题与可证伪主张

比较对象不是“会传结果的候选”与“只有SUCCESS标志的弱DAG”。普通强P&E已经能够分解任务、传递真实上游结果、读取历史、保留来源与版本、检查工具合法性、处理错误和重规划；同类能力的多个参数实例也应正常区分。

本次候选只增加两项协作机制：

1. 把**已声明的科学结果实例及其验收条件**作为程序完成边界；实际结果齐全且条件成立才自动完成和归档。它不证明模型从原自然请求中未遗漏目标，也不证明最终自由文本全都正确。
2. 根据DAG真实输入引用，在下一节点执行前选择**摘要、精确结果/工件或实际行动—观察过程**，保留按需升级读取。目的不是减少事实权限，而是在同一档案上减少不必要的呈现和管理步骤。

可证伪预期：在同信息、同科学底线、同工具能力下，候选能减少科学交付假阳性或无效证据读回，同时不增加完整任务成本至抵消收益。若强P&E同样正确且更便宜，收缩候选主张；若为强P&E加入相同自动验收后差异消失，说明这是可复用的验证适配，不是DAG无法实现的新算法。

## 4. 离线与真实评价必须分开

**离线受控机制层**通过真实工具执行、独立原采样oracle和必要Fake调用检查状态与数据流。可控制“漏一个必需输出却宣称完成”“额外辅助查询失败”“错误记录/版本引用”等反例；它们回答系统怎样处理这一输入，不估计真实LLM犯错概率，也不能以受控脚本预设的正确计划声称自主规划通过。

**未来同计划机制配对层**允许从自然请求产生一份真实模型DAG，原样用于A/B/C执行，所有组可合法局部重规划。共同规划成本只记一次并均摊，同时披露共享前史；这隔离执行/记忆机制，不能当作三组独立规划准确率。不得用研究者gold DAG替代该真实规划结果。

**未来端到端自主层**每组只收到自然请求、元数据和共同工具schema，模型自行提出DAG及局部动作。不同计划需单独归因，不能把计划质量差异直接当作记忆检索收益。本阶段没有付费模型授权，这两层的真实效果一律尚未验证。

配对单位是一条完整自然会话的A/B/C三个独立存储会话，数据、模型设置、科学合同、读权和上限一致。以ABC/BCA/CAB顺序轮换；预算不足则减少完整单位，不截断摘要或强基线。异常与首次失败保留，不能择优重跑。开发数据只作为开发；未来确认先冻结方法、请求、数据哈希、模型设置和评分，每单位一次。

## 5. 独立科学评分与费用

数值oracle从原合成样本重算，而非从候选的完成布尔值取真值：RMS用float64平方均值；连续PSD和事件功率用独立Welch及指定频带积分；事件有效数由真实事件与记录边界直接计算；差值/比值由独立两个操作数计算。数值容差`rtol=0.005/atol=1e-13`，整数计数精确；对象、时间基准、来源、参数、版本与实际工件必须准确。

请求级输出分为完整科学交付、正确科学停止、正确澄清、安全部分交付、错误/不完整。T06“实际3个，不满足≥4，不擅自扩大范围”是正确科学停止，不能因为任务未满足条件就算模型错误；把它写成满足条件才是假阳性。反过来仅有正确数值但漏必要结果，不能算完整交付。

报告以下可复查量：原请求逐项正确性、交付假阳性/遗漏、错对象/时基/版本复用、真正数值执行和重复数、修订额外计算、全部API输入输出tokens/调用、会话与API延迟、读取/恢复数，以及简单短任务管理开销。离线bytes只能描述呈现大小，不能代替实际API成本或延迟收益。

三级证据分别记录：①依赖和档案中应提供什么；②下一次真实模型输入实际含什么；③后续真实动作/回答用了哪些实际结果、字段或原工件。`restore`回执不是使用证明；完整历史已包含过程时直接使用同样合法。行为关联也不是机制因果收益，后者仍需配对和消融。
