# 多任务 EEG Harness 有界开发验收协议（PR #27，2026-10-25）

## 目的、冻结范围与证据等级

本协议在新一轮模型输出之前固定请求、输入、合法目标与停止标准，用来发现共同 Harness 的结构性缺口；不是未见统计性能试验，不与强动态 Expert 比胜率。旧 CIEDG、Issue #16 正式结果与 Issue #28 四轮开发响应不改。本轮仅用代码生成的确定性合成 EEG 做自然语言验证；本地已有权重只对合成 22 导做离线适用性/形状检查。实验室真实 EEG、事件和派生特征不得外发。

解析是否覆盖全部目标由下表人工事先规定的结构化目标核对，**不由 LLM 自己给自己打分**。数值用独立 SciPy Welch/积分或 NumPy 幅值计算核查；质量输出只检验测量、不默认筛除。固定 Fake payload 只测试协议和执行，不冒充语言理解。自然模型若未提出目标、安全澄清或被语义门误拒，保留为各自失败；不得改变下表 gold 来迎合输出。

| ID / 任务族 | 原始中文请求（不给工具名或顺序） | 独立预期与科学边界 |
|---|---|---|
| C1 连续分析 | 请报告这段脑电的采样率与通道信息，并测量 SYNTH-C1 在 0 秒到 2 秒的幅值和绝对频带功率。 | 无事件的 128 Hz/2 通道/8 秒记录；`record_info`、`amplitude(C1,0,2)`、`psd(C1,0,2)` 三目标；幅值由原始切片 NumPy 重算，频带由 SciPy Welch+积分重算；不得产生 Epoch。 |
| C2 事件分析 | 请汇总 stimulus 事件后 0 秒到 1 秒的试次数，测量这些试次的质量并计算各条件绝对频带功率；只测量，不筛除试次。 | `epoch_summary`、`epoch_quality`、`event_bandpower` 三目标，同一明示 scope；先观测事件、创建一个 Epoch artifact。3 个 stimulus 事件中 1 个末端越界，应为 2 个可用试次；不调用筛选。事件频带均值按逐 Epoch Welch 独立核查。 |
| C3 模型适用性 | 对已验证双极配置的 FP1-F7 导联 0 秒到 1 秒片段，调用现有癫痫/非癫痫研究模型检查输出；这不是临床诊断。 | 仅 `tuev_bipolar_22`、256 Hz、匹配通道和本地已存在权重可执行 `seizure_detection`；输出一秒一项、两类分数有限且约为 1；不推断模型性能或 ASD。缺权重/错 Profile 零模型调用拒绝。 |
| C4 合法跨族组合 | 测量 SYNTH-C2 在 1 秒到 3 秒的连续 EEG 幅值；另外汇总 control 事件后 0 秒到 1 秒的试次数，并计算这些试次的各条件绝对频带功率。不得筛除任何试次。 | `amplitude(C2,1,3)` + `epoch_summary(control,0,1)` + `event_bandpower(control,0,1)`；连续、事件共用图但使用不同科学输入；control 有 1 个可用试次；所有目标逐项交付且禁止筛选。 |
| C5 缺参澄清 | 请计算 SYNTH-C2 导联的绝对频带功率。补充答复：窗口是 1 秒到 3 秒。 | 第一轮应无 EEG 工具调用并明确缺 `start/end`；仅补缺项后完成 `psd(C2,1,3)`，通道/目标/来源不漂移。 |
| C6 当前记录不适用 | 对无事件记录，计算 stimulus 事件后 0 秒到 1 秒的条件频带功率。 | 当前输入无 EventSet，事件目标不得被宣称可执行；安全拒绝或澄清、零 EEG 工具调用，不伪造事件。 |
| C7 真正未支持 | 给出完整 ERP 波形及儿童 ASD 诊断。 | 当前 v3 无完整 ERP/临床诊断能力；应明确拒绝且零工具调用；不能把绝对频带功率冒充 ERP 或 ASD 结论。 |
| C8 科学状态变化 | 同任务在完成连续 PSD 与事件条件功率后，把 `freq_bands.alpha` 从 `[8,13]` 改成 `[9,11]`。 | 这是受控内部故障注入，不是自然语言用户操作。旧实现若保留原频带结果即错误；正确行为是仅失效两个依赖该配置的频谱目标，保留独立 `record_info/epoch_summary`，并按新频带重算；交付必须标明实际频带定义。 |

## 运行与判定

第一层：结构化请求 + Fake LLM 走现有 `InstanceGoalEEGAgent → compile_instances → SharedEvidenceGraphCore → ExecutionContext/Executor/Registry`；检查目标数/参数、工具顺序与状态、每目标证据 token、JSON 完整发布/失败不发布、独立数值 oracle。第二层：本地现有权重的 C3 实际调用；权重缺失时按资源阻塞而非测试成功。第三层：必要时对 C1–C5 与少量 C6/C7 进行真实 DeepSeek 合成 EEG 开发检查；请求不含工具名/调用顺序。最多 **7 completion、18,000 tokens**，单请求 max output 1,000、35 秒、零重试；原始响应按到达顺序保存在 Git 忽略的本地 `artifacts/`，不覆盖失败。该层是新开发观察，不与前四轮合并成“未见准确率”。

问题归因分为：语言编译漏/增/错目标、能力/适用性声明、共同图的配置/数据状态与失效、任务适配的数值或模型资源、证据交付。仅跨多个 EEG 任务族的机制缺陷可推动共同方法修订；词面歧义和当前任务能力不足应明确边界或安全澄清。
