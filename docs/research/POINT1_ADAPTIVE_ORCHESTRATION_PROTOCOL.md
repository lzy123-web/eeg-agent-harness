# Issue #32 预实现最小实验协议（开发集与未见组合）

冻结于核心原型代码写入之前；以本文件首次提交为协议版本。原始 CIEDG/Issue #16/PR #23/#27/#31 结果不改。所有样例是确定性合成 EEG；本协议只测结构化目标后的执行策略，不把自然语言解析准确率混入主评分。没有临床试次充分性标准：`minimum_valid_epochs` 是**请求者显式给定的研究条件**，不是算法推断的诊断阈值。

## 预测与判据

- H1 动态行为：同一事件功率目标，在事件不足、事件足够但边界后 Epoch 不足、Epoch 足够三种记录上，下一步分别停于事件观察、停于建 Epoch、继续频带功率。不能改事件标签、窗口或筛选试次。
- H2 跨族成本：原子组合任务中先验证会使整单失败的事件前提，可避免失败时无谓连续 PSD；不需要事件检查的连续任务不得多调 `list_events`。固定计划允许同规则 preflight，但按固定目标顺序执行；动态 Expert 可使用相同条件分支，预计可能与候选持平。
- H3 扩展面：若只是增加一个遵守现有工具合同的只读连续目标，研究策略不应新增单独流程；若仍需大量任务名分支，记为反证。不在本轮用 LOC 单指标证明创新。

主 oracle 独立于候选策略：对合成数组直接切片，以 SciPy Welch+积分重算连续和事件 alpha 功率；按事件时间与记录长度直接计算边界内 trial 个数；根据请求授权、Profile、资源和全部目标是否有当前结果评分。**工具返回 `success` 本身不算科学正确。**每臂相同输入、Registry/Executor、Profile、资源、20 tool-call 上限；目标未满足时不得发布完整 bundle。评分拆为科学正确/误发布、完成/安全停止、无谓检查、真实工具调用、耗时。Strong Expert 是独立的人工条件 DAG，可观测相同事件摘要和 Epoch 结果；静态臂共享严格 preflight 但不调整固定目标顺序。Native/ReAct 如不做等条件真实 API 实验，只列 N/A，Fake 不冒充。

## 冻结开发案例（可修原型 Bug，须留首次失败）

合成默认记录 8 s/128 Hz、两通道正弦；默认事件 `stimulus` 在 1、3、7.8 s，`control` 在 5 s；`[0,1)` Epoch 中末端 7.8 s 被边界排除。连续 PSD 用通道 `SYNTH-C1`、0–2 s、配置 alpha 8–13 Hz。事件功率用 `stimulus` 或 `control`、`tmin=0,tmax=1`。

| ID | 目标/条件 | 独立预期与计划分支 |
|---|---|---|
| D1 | 单 PSD | 成功；仅 `psd`，不能无谓检查事件。 |
| D2 | `stimulus` 事件功率，min-valid=2 | 先 `list_events` 得 3，再 `create_epochs` 得 2，有效后 `event_bandpower`；独立数值匹配。 |
| D3 | `control` 事件功率，min-valid=2 | `list_events` 仅得 1，科学停止，不建 Epoch/不发布。 |
| D4 | `stimulus` 事件功率，min-valid=3 | 原始事件为 3，建 Epoch 后仅 2；在 `create_epochs` 反馈处停止，不调用功率。 |
| D5 | PSD + D3（原子整单） | 先事件门控并停止；不调用不可能发布的 PSD。 |
| D6 | PSD + D2（原子整单） | 两目标都完成，PSD 与事件功率均经独立 Welch 验证。 |
| D7 | D2 但禁止 `list_events` 额外观察 | 不得调用禁用工具；可直接按授权标签建 Epoch，实际试次数够则完成功率。 |
| D8 | 事件功率缺 `labels`，没有“全标签”授权 | 零工具澄清，不自行选择标签。 |
| D9 | 模型目标在原生 2 导 Profile/缺权重 | 零模型调用，结构化不适用/资源失败；不得用该结果作任何疾病解释。 |

## 冻结未见组合（不得按其结果改主张、gold 或对手）

用新建的确定性合成事件位置/标签组合，保持 128 Hz/两通道；不是开发样例改一个同义词。

| ID | 数据/任务 | 独立预期 |
|---|---|---|
| H1 | 12 s，`target` 在 2、4、6 s；事件功率 min=3 + 连续 PSD | 3 个有效 Epoch，两目标完成，SciPy 重算数值相符。 |
| H2 | 8 s，`target` 在 7.2、7.7 s；`[0,1)` Epoch，min=2 | inventory 得 2，Epoch 全越界，工具返回结构化失败；不能继续功率或发布。 |
| H3 | 无事件 + 连续 PSD + `target` 事件功率 min=2 | 必需事件观察为零，整单安全停止且 PSD 不应提前执行。 |
| H4 | `target` 事件足够，但连续目标请求不存在的通道 | 原子静态 preflight 零工具拒绝，不得先执行事件链。 |
| H5 | 12 s，`target` 在 2、4 s；min=1、禁止事件观察 | 直接建 Epoch、事件功率完成；不调用 `list_events`。 |

事件 `minimum_valid_epochs` 只用于**停止/继续**，不被解释为真实科研中可靠性充分。候选既不筛选试次，也不自动选择标签或修改参考。S09、C1–C8 和质量 Pilot 不参与本协议的未见计分。
