# 工作点一研究决策：CIEDG 是否具备硕士论文创新价值

日期：2026-10-24（Asia/Shanghai）  
决策：**Conditional-Go（可作为工作点一继续写作，但当前证据不足以主张优于强专家或端到端可靠）**

## 研究对象

CIEDG 的研究对象不是某个 EEG 算法，而是：在多步骤 EEG 工具执行中，用 EEG 科学属性、artifact 角色、内容 fingerprint、目标—证据依赖和失效传播，维护剩余科学目标，并在状态变化或资源失效后进行有界局部恢复和证据受限回答。

## 支持保留为论文工作点的证据

1. 机制实际接入原 Agent、Registry、Executor 和真实 EEG 工具，不是离线模拟器或单纯 Prompt。
2. 同一机制跨越质量筛选与显式 Epoch 重参考两个科学状态转换族；能区分 source/effective、identity/content 和转换前后证据。
3. 去掉 EEG scientific guards 后 4/24 出现未经授权转换，说明科学约束有可观察的因果作用。
4. 相比 whole-plan replay，CIEDG 在相同正确性下由 121 降至 109 次调用；失效传播和语义复用消融各增加 3 次调用。
5. R11 显示不同 identity、相同内容 fingerprint 时，旧 summary 可复用但 release provenance 必须换绑当前 identity；这比“失败后重跑”更具体地体现了内容/来源分离。

## 不支持夸大创新性的证据

1. Strong Dynamic Expert 与 CIEDG 均为 24/24、109 次调用；排除无效 S09 后仍完全持平。没有相对正确率、成本或恢复优势。
2. 正确率差异主要来自 guard 消融；Prompt、Schema、Validator 或显式规则本身不是足够的方法创新证明。
3. 依赖传播与语义 cache 消融没有正确率下降，只观察到很小的调用成本变化。
4. 真实 DeepSeek 分层子集 CIEDG 仅 1/4，表明自然语言解释与最终回答仍会阻断正确核心执行。
5. 实验只覆盖合成 Epoch、两个转换族和绝对频带功率；没有真实数据、多数据集或复杂任务泛化证据。
6. S09 的协议构造无效，selection 家族的等价派生内容复用仍缺正式证据。

## 客观判断

CIEDG **具备作为硕士论文工作点的结构化方法雏形**，其可辩护贡献应限定为：

- EEG 科学状态与目标证据的显式、可审计联合表示；
- 内容等价与来源身份分离下的证据失效/换绑；
- 在合法转换和有界故障下的局部恢复；
- 将最终答案限制到当前有效证据。

当前不能声称：

- 比同规则强专家更准确或更高效；
- 已解决自然语言 EEG Agent 的可靠性；
- 已在多个 EEG 数据集、临床任务或真实受试者上验证；
- 质量阈值或结果具有临床意义；
- 仅凭 24 个场景已经证明普遍创新性。

因此决策不是无条件 GO。若论文必须以“性能显著优于强专家/原生 Agent”为核心主张，则当前结果为 **No-Go**；若主张聚焦“可审计科学状态—证据依赖与有界恢复机制”，并如实呈现强专家持平和真实 LLM 失败，则为 **Conditional-Go**。

## 论文写作建议

方法章节应冻结为当前 CIEDG，不再新增第三转换或新规划器。实验章节将三类问题分开：

1. Parsed-task 核心机制：科学正确性、失效恢复、provenance、工具成本；
2. Natural-language interface：意图解析和回答证据失败，作为端到端边界；
3. 科学有效性边界：经验阈值、合成数据、单 trial 与参考通道 flatline。

应同时报告 Strong Expert 完全持平、S09 protocol-invalid、真实 LLM 1/4 与 0/4，而不是只报告成功案例。

## 后续允许与禁止

允许的后续工作仅限：

- 扩大**预注册**的独立复现实验样本与统计功效；
- 在不改方法/真值的前提下增加真实但不外发的数据本地验证；
- 把 Intent、Planner、State、Recovery、Answer 五层错误评价写清楚；
- 对论文主张做消融和有效性威胁分析。

禁止继续通过新增状态转换、规则、Prompt 特例或 holdout 后调参追求优势。任何未来方法修订必须另立版本和新协议，不能覆盖本次 v1 结果。
