# Issue #32 工作点一一页研究决策

**研究什么？** 通用多任务 EEG Harness 如何在一个请求内，根据各目标的科学前提、授权和真实工具反馈，决定**是否先观察、先验证哪个前提、何时展开派生分析、何时停止及何时整单发布**。不是让 LLM 多调用工具，也不是 CIEDG 的 DAG/来源/投影改名。

**本轮提出什么？** 一个 opt-in、确定性的“科学需求—反馈渐进编排”原型：先原子预检所有目标；对请求者明确给出试次下限、且可被事件清单提前否定的事件作用域，只调用一次真实 `list_events` 覆盖全部作用域；再由真实 `create_epochs` 输出的边界内有效试次数决定是否展开 `event_bandpower` 等消费者；最后运行独立连续/严格模型工具并只在全部目标完成时发布。禁止的观察不会调用，标签、窗口、参考与试次不会自动改写。原有 Registry/Context/Executor 和数值算法未替换，不使用子 Agent、质量阈值换窗或第二执行器。

**与已有方法的实质差异？** 相对单次任务名 router 和固定用户顺序，**中途证据真正改变计划**：同一事件目标在事件不足、边界损失、有效试次足够时分别停在不同层；组合任务可免做注定不能发布的 PSD。相对 [ReAct](https://arxiv.org/abs/2210.03629)、[HTN](https://www.cs.umd.edu/~nau/papers/erol1996complexity.pdf)、[CogEEGAgent](https://arxiv.org/html/2607.25045) 和成熟条件工作流，这些动态策略并非不可复制；EEG-specific 内容是事件作用域、Epoch 边界、请求者声明的有效试次条件、Profile/资源门控。**不能声称发明了动态规划或科学合同。**

**实验证据支持什么？** 预冻结开发 D1–D9 候选 9/9、14 calls；一次未见 H1–H5 候选 5/5、9 calls；SciPy/NumPy 独立核对连续和事件 alpha 数值及边界内试次。后设 D10 首次发现跨事件 scope 的无谓 consumer，保留失败轨迹；全局门控修订后只需一次 inventory。现有真实模型权重只在本地合成 22 导 Profile 做输出结构检查，不涉及临床准确率。外部 API 0 次。

**反证是什么？** 同规则 Strong Dynamic Expert 在开发 **9/9、14 calls**、未见 **5/5、9 calls**，与候选完全持平；D10 同样能修复到 1 call。固定用户顺序也全部科学正确，只在 D5/H3 各多 1 次不能发布的 PSD。多增加一个已注册幅值目标时双方都不需新策略分支。耗时为毫秒量级且无稳健差异。结构化目标实验不解决自然语言漏目标，也不校准真实 EEG 试次充分性。既有 Issue #16、PR #23 强对照负结果继续有效。

**决策：有限 REFINE，尚不可作为已成立的硕士论文算法创新。** 本原型证明了通用 Harness 中有用的 EEG 领域条件编排行为，但未证明比合理动态 Expert 更正确、更省调用或更易扩展。下一步**唯一值得做的决定性实验**是预冻结一项跨连续/事件的新增分析能力和多科学作用域组合，以相同工具、科学规则、反馈、授权和预算测量双方**新增科学声明、专用分支、审查工时、误发布及恢复代价**；不靠 LOC 一项，也不改弱 Expert。若仍同等成本与正确性，则 **STOP 把本机制包装为独立算法**，保留为系统工程方法；不再补第三种状态转换或大量提示词。该实验需要提前确定独立科学 oracle 与确实新增的能力，否则不启动。
