# R3 综合应用准备度与资料缺口（Issue #24）

## 已具备的能力

冻结 CIEDG 已通过离线应用桥处理固定 4 份真实 R3 EDF：在项目显式配置的数字事件标签上完成事件/有效窗口汇总、Epoch 质量测量及绝对频带功率；与原确定性链和独立切窗/PSD 数值检查一致。`EEGRecord`、`EventSet`、`EpochSet`、`ExecutionContext`、Registry/Executor 与证据依赖图均为现有实现。该结论只支持“在既有配置下计算链路可运行且数值一致”，不是 EEG 范式解释或临床有效性结论。

质量工具给出经验筛查证据，默认不删试次。`event_bandpower` 是整个 Epoch 的绝对功率，不是 ERD/ERS、ERP、动作类别识别或 ASD 诊断。真实 R3 完全离线处理，未与 DeepSeek 形成真实数据闭环。

## 阻断更高层结论的最小资料

| 下一步科学任务 | 需要的可核验证据 | 缺失时的边界 |
|---|---|---|
| 给数字事件赋予动作/刺激条件意义 | 正式实验方案或刺激日志，列出代码 1–9、时间锁定点、Boundary/休息规则 | 仅报告数字代码，不解释条件 |
| 论证 Epoch、baseline、滤波、参考及质量规则 | 采集设备/原始参考与硬件滤波记录、预处理方案、坏道与伪迹标注规范 | 当前仅为显式分析配置，不称科学最佳方案 |
| 受试者级特征、重复记录处理与组间比较 | 经授权的文件—唯一参与者—重复记录—正式组别/诊断与纳排映射 | 不把 EDF 当独立受试者，不按目录名推断 ASD/TD |
| 核对统计表与 EDF 资源 | 权威文件清单或更正后的记录关联表 | 本地计数 JSON 只作来源线索，不作身份真值 |
| 应用性能或临床评估 | 上述资料、预注册标签/分组、数据治理许可、独立评估协议与误差分析 | 不输出分类指标、显著性或诊断结论 |

目前无法从现有 EDF、两份逐文件计数 JSON 和非权威说明中确认这些字段；不要求重复提供已经从 EDF 可查的 21 导、300 Hz 与数字 annotation 事实。

## 研究判断

真实数据接入说明冻结方法的事件证据/状态链能够复用到一个实际应用，并暴露“计算可重复”与“科学解释有依据”之间的清晰边界。这是应用集成与可行性证据，**不能包装为第二创新点，也不能弥补工作点一与强 Expert 持平的既有结果**。下一阶段若资料齐备，先核准科学契约与受试者映射，再设计应用层统计/评估；若仍缺失，只保留匿名、离线、数字事件计算，不扩张到 ASD 辅助评估主张。
