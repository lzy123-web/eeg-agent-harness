# R3 科学数据契约（Issue #24）

## 证据层级

本文件仅陈述应用接入所需的数据契约。真实 EDF、单记录事件、特征、路径和完整 trace 均保存在本地，不进入仓库或外部模型。旧 `R3_INTEGRATION_REPORT.md` 是历史诊断；本轮先核对资源清单，再对固定子集重新运行。

| 项目 | 当前依据 | 状态与可用边界 |
|---|---|---|
| 本地 EDF 数 | 已授权资源根目录的只读清单：两个存储分区，共 69 份 EDF | 文件存在事实；分区名不构成受试者或诊断组真值 |
| 通道与采样率 | 旧报告逐文件实测 21 EEG + Status、300 Hz；本轮子集重新核验 | 数据结构事实；Status 不进入 EEG 数组 |
| 事件表示 | EDF annotation 为数字字符串 1–9；本地统计 JSON 为逐文件标签计数与 `Hint` | 数字代码可用于显式指定的计算，含义尚未确认 |
| 标签 9 | 统计 `Hint` 说“可能是 Boundary”；其他记录的 `Hint` 也出现标签 3 或 5 的可能性提示 | **未验证**；不可写成确定边界真值 |
| 标签 1–8 | `R3DatasetRules.analysis_labels` 的现有分析配置 | **配置假设**，不是已确认动作/刺激条件；本轮仅按原配置复现数字标签特征 |
| 预处理 | `R3_PROFILE`：21 通道、300 Hz、1–40 Hz 带通、50 Hz 陷波、平均参考 | 通道/采样率为结构核验；滤波与参考的科学适用性未获采集方案确认 |
| Epoch | `R3DatasetRules`：`[-0.2, 0.8)` 秒，baseline `[-0.2, 0)` | 可复现分析配置；实验依据和刺激时间锁定含义未验证 |
| 质量 | 现有 `epoch_quality` 的经验规则 | 只测量、记录；本轮不自动剔除试次或通道 |
| 频带功率 | 现有 `event_bandpower`：整段 Epoch 的 Welch 绝对功率 | 可复现数值；不是 baseline-normalized ERD/ERS、ERP 或临床指标 |
| 文件—参与者—组 | EDF 与逐文件计数 JSON 不提供可采信的唯一参与者 ID、重复记录关系、诊断确认和组别映射 | **缺失**；不以目录/文件名推断，不做受试者级或组间统计 |

本地 `data_overview.md` 的目录组别推断、标签 9 建议及建模设想不是权威实验说明。它还记录统计表与磁盘 EDF 清单不完全一致；本轮以实际 EDF 为运行输入，统计表只作为待核实的来源线索。

## 当前可执行任务

1. 核验记录结构、实际事件代码和窗口边界。
2. 在**显式配置的数字标签**上创建 Epoch，汇总接受与边界拒绝试次。
3. 对相同 Epoch 测量经验质量证据并计算绝对频带功率，核对 provenance 和数值。

这些结果仅说明技术链路与当前配置下的数值一致性，不能解释动作条件、生理效应或 ASD 状态。
